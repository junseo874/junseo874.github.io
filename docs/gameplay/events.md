# 본편 사건과 대화 흐름

[본편 구현 확정 기준으로 돌아가기](README.md) · [데이터 연결 방법](data-and-dialogue.md)

현재 새 게임의 실제 흐름을 기준으로 한다. 아래의 “기록/유지”는 실행 중 일차·장면 간 상태 유지이며 앱 종료 후 저장을 뜻하지 않는다. 전체 대사는 복사하지 않고 CSV와 실행 키로 찾는다. 이후 새 콘텐츠는 해당 사건의 항목을 갱신한다.

## 부비

**시작:** 2일차 출근부터 집 앞 복도. 아직 입양하지 않았다면 이후 일차에도 남는다.

1. 처음 가까이 가면 박스 흔들림 8프레임을 한 번만 재생하고 `boobi_box_shaken`을 기록한다. 이후 빈 박스 정지 프레임으로 대기하며, 재접근해도 흔들림이나 눈 반짝임을 반복하지 않는다. 이 접근만으로 입양 대화가 시작되지는 않는다.
2. 박스에 E → 눈 반짝임 22프레임을 한 번 재생 → 등장/점프 15프레임을 한 번 재생하여 옆 박스에 착지 → `boobi_revealed`. **여기서 끝나고 조작 복귀**한다.
3. 부비에 별도로 E → “야옹”과 쓰다듬기/참치캔 주기/취소 선택.
4. 참치캔이 없으면 불가 연출만 표시. 가지고 있으면 `boobi_feeding_pending`을 기록하고 먹기 → 루나 대사 → 옆집 주민 접근·대사·퇴장 → 암전 → 집 이동으로 이어진다.
5. 입양 전환에서 `boobi_adopted`를 기록하고 pending을 해제한다. 집 소파 위 부비와 루나의 마지막 대사 뒤 종료한다. 참치캔 보유 해금은 소비하지 않는다.
6. 입양 후 처음 휴식하면 `neighborhood/rest`를 먼저 실행한다. 암전 → TV 오른쪽에 크리스 고정 배치 → 고정 배율의 좌→우 카메라 이동 → 대사. 정상 종료 때 `boobi_rest_seen`을 기록한다.
7. 이어서 해당 밤 테라스/수면과 일차 마감으로 돌아간다. `workshop`은 끼워 넣지 않는다. 입양 직후 휴식하지 않아도 첫 반응은 다음 휴식까지 남는다.

집의 부비는 “꾸륵 꺍.” → 쓰다듬기/취소. 쓰다듬기는 눈·꼬리·하트 반응 후 복귀하며 돈이나 첫 휴식 상태를 변경하지 않는다. 이 사건의 미연결 사운드 큐는 기본 무음이며 임의 음원을 추가하지 않는다.

## 수리공과 엘리베이터

**시작:** 1일차 출근부터 엘리베이터 하단 오른쪽. 수리하지 않으면 이후에도 남는다.

- 첫 E → 인사/불평 → 대화한다/무시한다. 설명을 정상적으로 마치면 `repairman_met`.
- 재상호작용 → 기어 부품/400원/취소. 보유/돈 조건을 확정 시 다시 검사한다. 기어 부품은 1일차 하층의 신문 읽는 남자와 대화해 얻는다(`inventory.gear_part`). 포트에게 받는 사건은 없다.
- 거래 확정 시 400원 경로는 돈을 차감하고, 두 경로 모두 `elevator_repair_paid`를 기록한다. 기어는 보유 해금을 소비하지 않는다.
- `repairPaid` 대사 → `repair` 액션 → 암전 중 `elevator_repaired` → 마지막 수리 완료 대사.
- 마지막 대화 종료 시 `엘레베이터 수리!` 목표 달성 알림을 한 번 표시하고 수리공이 퇴장한다. paid 상태로 중단된 경우 다시 차감하지 않고 완료 흐름으로 이어간다.

엘리베이터는 E 즉시 이동하지 않는다. 하단은 올라간다/취소, 상단은 내려간다/취소. 수리 후에는 **빠른 이동이 첫 번째**, 일반 이동이 두 번째, 취소가 마지막이다. 빠른 이동은 암전 후 반대 층으로 이동하며 본편 귀가 조건 검사도 통과해야 한다. 일반 이동 중에는 난간 밖 이동을 허용하지 않는다.

## 모닥불 갱단

**시작:** 0일차 퇴근부터. 경비 앞 경계는 이동만 막으며 닿았다고 강제로 대사를 시작하지 않는다. E로 대화한다.

- 2일차 출근 전에는 통행을 허가하지 않는다.
- 2일차 출근부터 술 질문/자리를 뜬다. `guardPass`의 와일드 독 질문과 중앙 남자 안내를 **끝까지 마친 뒤** `gang_pass_granted`를 기록해 경계를 푼다.
- 중앙 보스 첫 대화는 `bossIntro`, 이후는 `bossRepeat`. `boss-met` 액션이 `gang_boss_met`을 기록한다.
- 기다린다 → 거래 없이 종료. 수리 완료 또는 500원 → 조건을 재확인한 뒤 해당 거래 대사로 진행한다.
- 돈은 확정 시 차감하고 `gang_wild_dog_paid`, 수리 경로는 `gang_wild_dog_repair_promised`를 기록한다. 첫 거래/재방문 대사는 `gang_wild_dog_repeat_deal`로 구분한다.
- `wild-dog-grant` 액션에서 와일드 독 지급·획득 알림·`gang_wild_dog_received`를 처리하고 거래 대기 플래그를 지운다. 중단 뒤에는 같은 거래를 이어가며 재차감하지 않는다.
- 이미 받았다면 `bossDone`. 옛 시바견 구매 기록/기존 보유분도 중복 지급 방지에 반영한다.

대화 전에는 모닥불을 중심으로 서로 마주본다. 플레이어 이동만으로 전원이 따라 보지 않는다. 직접 대화의 대상/참여자만 루나를 보고 종료하면 원래 방향으로 돌아간다.

## 시바견 상점

**시작:** 2일차 출근부터 3일차까지, 거리 하단.

```text
첫 만남 설명 또는 재방문 인사
  → 재방문은 한번 볼게요 / 아니요
  → 상품 확인
     → 두 재료 보유 + 아직 학습 전이면 학습·퀴즈
     → 아니면 용돈 조건에 해당할 때 지원 선택
     → 아니면 상품 목록
```

- 상품 목록의 첫 선택은 **구매하지 않는다**. 비터스 300원, 참치캔 50원. 참치캔은 2일차 출근부터, 미보유·부비 미입양일 때 상품 단계에만 나타난다. 인사 선택에 바로 끼워 넣지 않는다.
- 와일드 독은 팔지 않는다. 소지금 부족 시 외부 공통 거부 연출, 이미 산 상품은 재구매시키지 않는다.
- 구매한 물품은 선택지에서 제거한다. 현재 팔 수 있는 물품이 전부 없어지면 재방문 인사·‘한번 볼게요’·빈 상품 목록 대신 ‘이제 팔 거 없어. 꺼져, 시바.’ 대사로 종료한다. 단, 미완료 올드패션드 학습·퀴즈 조건이 충족되면 이 별도 사건은 계속 진행할 수 있다.
- 상품 선택 중 시바견의 ‘…전부 다 보여 주긴 싫고 몇 개만 보여 줄게.’ 대사를 유지한다. 별도의 ‘어떤 걸 살 거야?’ 질문은 사용하지 않는다.
- 구매 확정 시 돈·`shiba_bought_*`·인벤토리를 함께 갱신한다. 이후 대사를 취소해도 구매를 없던 일로 돌리거나 중복 결제하지 않는다.
- 용돈은 상점이 열리는 2일차에 소지금 300원 이하이면서 아직 받지 않은 경우 제안한다. 수락 대사의 `shop-allowance-grant`에서 500원과 `shiba_allowance_received`를 함께 기록한다. 플레이 전체 한 번이며 거절은 지급 완료가 아니다.
- 비터스와 와일드 독을 모두 보유하고 `shiba_old_fashioned_taught`가 없으면 학습/퀴즈. 비터스를 두 번째로 샀다면 구매 답변 뒤, 와일드 독을 나중에 얻었다면 다음 상품 확인에서 시작한다.
- 오답은 다시 설명·퀴즈, 정답은 학습 완료 기록. 퀴즈는 구매 조건이 아니고 추가 차감/아이템 지급이 없다. 이 기록을 실제 올드패션드 제조 해금과 혼동하지 않는다.

## 사기꾼과 근처 행인

**등장:** 0일차 퇴근길에만 사기꾼과 근처 행인 모두 등장한다. 1일차 출근부터는 미지급·미대화여도 나오지 않는다. `outside-beggar.js`가 날짜·방문 상태를 판단한다.

- 사기꾼 첫 대화/재방문 대사는 `street_beggar_met`으로 구분한다. 200원 준다/거절/사기꾼 질문의 세 분기다.
- 행인의 경고 대화를 완료해야 `street_beggar_warned`가 생기고 특수 질문이 열린다. 그 전에는 `???`.
- 200원 지급은 차감과 `street_beggar_paid`를 함께 기록한다. 열 배로 돌려준다는 **대사는 보상 지급 명령이 아니다**.
- 지급 대사 후 사기꾼이 떠난다. 행인은 그 거리 방문 동안 지급 후 반응을 볼 수 있지만 이후 재방문에서는 사라진다.
- 행인의 미지급/지급 후 첫 대화와 반복 대화를 별도로 구분한다. 정보를 얻는 완료 시점과 단순 첫 접근을 합치지 않는다.

## 신문 읽는 남자

- 1일차 출근/퇴근 하층의 변기(`2 toilet_bin`) 앞, x=-7.08 / 발끝 y=-0.974. 기존 M2 실루엣·공유 0.75초 Idle을 사용하며 전용 신문 애니메이션은 없다. 접근 강제 대화가 아니라 E 상호작용이다. 대화할 때 루나를 바라본다.
- `newspaper/intro` → 두 선택지(`wrong`, `right`) → `common` → `finish`. 선택지 문구는 `newspaper/options`에서 읽으며 선택 직후 NPC 답변으로 이어진다. 두 분기 모두 동일한 보상으로 합류한다. 선택지에서는 직전 질문 말풍선을 유지한다. 대사는 `story/scenes.csv`, `steps.csv`, `web-views.json`에서 관리한다.
- `grant-gear` 행에서 `inventory.gear_part` 1개와 `newspaper_gear_received`를 함께 기록하고 획득 알림을 표시한다. 수리공이 읽는 기존 부품과 동일하며 별도 부품 ID를 만들지 않는다. 기존 부품 보유·수리 완료 여부와 무관하게 이 NPC의 보상은 플레이 전체 한 번이다.
- 마지막 인사 완료 시 `newspaper_conversation_done`과 `newspaper_completed_flow`를 기록한다. 출근길에 완료했다면 퇴근길에는 나타나지 않는다. 현재 출근/퇴근 구간에서는 남아 짧은 인사만 반복한다. 보상 전 중단은 첫 대화부터, 보상 후 중단은 마무리 인사부터 이어가므로 중복 지급하지 않는다.
- 돈·플래그·수리 상태를 초기화하지 않는다. 보상/완료 기록과 인벤토리는 캠페인 carry에도 반영되어 영업·퇴근 이후 유지된다. 대사 속 통계·자유에 관한 주장은 NPC의 대사이며 게임 시스템의 사실 판정이나 보상 조건이 아니다.

## 기신교 신도

- 하층 보라색 간판 가게의 셔터 앞(x=4.7 / 발끝 y=-0.974). 기존 M1 실루엣과 공유 Idle을 사용하고 E로 대화할 때 루나를 바라본다. 전용 신도/엠블럼 이미지는 아직 없다.
- 등장 기간은 0일차 퇴근길과 1일차 출근길·퇴근길. `believer_conversation_done`이면 같은 길을 포함해 더 이상 표시/상호작용하지 않는다. 0일차 출근, 2일차 이후, 상층, 집, QA 전용 상황에는 나오지 않는다.
- `believer/intro`의 초대 대사 → `believer-action / grant-emblem` → 마지막 인사 순서이며 선택지는 없다. CSV의 `story/scenes.csv`, `steps.csv`, `web-views.json`이 대사 원본이다.
- 지급 시 `inventory.machine_church_emblem` 1개와 `believer_emblem_received`를 기록하고 ‘기신교의 엠블럼 획득!’ 알림을 띄운다. 칵테일 재료가 아니며 모임 입장 기능을 새로 만들지는 않는다.
- 마지막 인사를 넘겨 대화를 끝내면 `believer_conversation_done`을 기록한다. 보상 전 중단은 처음부터, 보상 후 중단은 `believer/finish`의 인사부터 이어져 중복 지급하지 않는다. 인벤토리·플래그는 본편 `session.carry`에 함께 반영한다.

## 강제 사건과 주변 대화

강제 사건들은 공통 대기열을 거치지만 세부 상태는 각 사건이 소유한다.

| 사건 | 본편 조건과 종료 기록 |
| --- | --- |
| 1일차 복도 불량배 | 1일차 출근, 상층 복도 지정 범위. 지불/거부 선택과 액션, 퇴장·카메라 복귀 후 `day1_thug_done`. 지불은 선택 확정 시 500원 |
| 2일차 불량배 | 2일차 출근, 상층 복도의 고양이 오른쪽 옆집 문 앞. 문 근처에 접근하면 시작하며 고양이·박스 앞에서는 시작하지 않는다. `day2_thug_done` 전 강제 재회, 이후 정보 상호작용은 별도 대상/분기 |
| 밀수 거래 목격 | 1일차 퇴근, 하층 지정 범위. 대화와 카메라 복귀 후 `day1_trade_done` |
| 삼호 출근 | 2·3일차 출근, 하층 삼호 근처. 진입→대사→퇴장→카메라 복귀 후 `day2_samho_done` / `day3_samho_done`, `samho_met` |
| 3일차 계약 | 3일차 퇴근, 지정 인물 근처. 계약 관련 대화 → 밀수업자 퇴장 → 삼호 접근·루나와 대화 → 삼호 퇴장·카메라 복귀 후 `day3_contract_done`. 플레이어 계약 선택지를 임의로 추가하지 않음 |

2일차 불량배 정보 상호작용은 갱/코라테크/크리스 주제 선택 → 50원 지불 확인 → 해당 설명이다. 확정 시 돈을 차감한다. 현재는 해당 정보를 샀다는 영구 해금으로 재방문 가격을 없애지 않으므로 다시 구매하면 다시 50원이 든다. 취소는 대화 종료, 부족하면 공통 불가 연출이다.

이 표의 범위 숫자와 액션 순서는 각 모듈의 `offer`, `choiceView`, `choose`, 액션/완료 함수가 정본이다. 같은 날짜라는 이유로 다른 위치에서도 자동 시작시키지 않는다.

주변 잡담은 주 사건이 아니다. `BackgroundStories`의 독립 채널·거리 조건·완료/재진입 조건을 사용하며 직접 대화 중 멈춘다. 4초 공통 간격이 있다고 모든 1회 잡담을 영구 반복으로 바꾸지 않는다. TV의 자동 방송과 E로 시작하는 TV 컷씬도 서로 다른 흐름이다.

## 집과 조사 오브젝트

외부 복도에서 집 문으로 들어오면 실내 출입문 바로 안쪽에서 방 안쪽을 바라보며 시작한다. 전환 암전 중 위치를 바꾸며, 방 중앙의 `HomeSafeSpawn`은 문 진입에 사용하지 않는다. 기상·이벤트·개발자 장면 초기화의 시작 위치는 별도로 유지한다.

| 대상 | E 상호작용 결과 |
| --- | --- |
| 침대 | `home/bed`의 루나 혼잣말. 수면 기능 아님 |
| 옷장 | `home/wardrobe` → 누른다/취소 → 누르면 `home/wardrobePressed` 대사만 |
| 탁자 책 | 포스터와 같은 이미지 조사 화면. `《즐거운 학문》 - 프리드리히 니체` |
| 시바견 포스터 | 이미지 조사 화면. 이 조사에 개 짖는 소리를 붙이지 않음 |
| TV (모든 일차) | 외부 모델 시작 시 꺼짐. 근접 안내는 `TV 상호작용`. E는 전원을 켜고 `본다 / 끈다 / 취소`를 표시한다. `본다`는 해당 일차·시간대의 시청용 컷씬을 실행하며, 미배정이면 선택을 유지한 채 빨간 거부 연출과 `볼만한 방송이 없습니다.`를 표시한다. `끈다`는 화면 레이어·방송 말풍선을 끄고 메뉴를 닫는다. `취소`·Esc는 전원을 유지하며 메뉴만 닫는다. 현재 시청용 컷씬은 기존과 같이 0일차 출근/퇴근의 TV 다큐이며 재시청 가능. 자동 말풍선은 켜진 상태에서만 0일차 출근 다큐, 0일차 퇴근 뉴스 1, 1일차 출근 뉴스 2로 분리된다. 컷씬 복귀 후에도 켜진 상태를 유지한다. 다큐의 스캔라인은 대사 대기 중에도 재생하며 설정·포커스 일시정지만 따른다. 전원은 세이브 플래그가 아닌 현재 외부 모델 상태다. |
| 소파 | 휴식 선택과 현재 본편 마감 조건 검사. 부비 첫 반응과 밤 장면 연결은 공통 진행 규칙 참조 |
| 문·바 입구 | 현재 안/밖·출퇴근·일차 조건을 확인해 장면 전환. 이전 말풍선/입력 정리 |

모든 대상에 물음표는 없다. 조사 화면의 나가기 안내도 공통 상호작용 표시를 사용한다. 집 안 부비는 별도 NPC 상호작용이며 소파 휴식 선택과 합치지 않는다.

## 바와 밤 대화의 추적 순서

### 본편 대본 기준 · 바 2026-11-01 / 외부 원고 2026-11-03

[기현 수정본](https://app.notion.com/p/3ef1612298dc8016864be134bcc832e8)의 0~3일차 **바 내부, 테라스, 연결된 유나·조니 회상**을 반영했다. 3일차 접힌 `옛날 것들`은 본편으로 가져오지 않는다. 실제 편집 원본은 `story/steps.csv`, `bar_choice_groups.csv`, `bar_choices.csv`이며 런타임 파일은 생성물이다.

| 일차 | 반영된 진행과 예외 |
| --- | --- |
| 0 | 새 튜토리얼 선택 → 진 토닉 → 포트 진 피즈. 제공 후 자연스럽게 팁 대화를 추가하고 **100원 한 번** 지급. 예전 진 피즈 역사 선택은 제외. 밤에는 유나와 감정에 관한 짧은 회상 |
| 1 | 맥주 튜토리얼 → 시바견 맥주 → 톰 드라이 마티니 → 아일리 **스크류드라이버**. 수정본의 샴페인 주문만 대사·실제 주문 함께 변경. 톰의 이름 소개 알림 ID `campaign_d1_bar_77`은 유지 |
| 2 | 삼호 자유 추천 → 포트 칩 전달·맥주 → 루나 퇴장 뒤 크리스·포트 대화. 휴식 시 **크리스와 테라스 대화 → 조니 회상 → 테라스 복귀**. 외부 최신 원고에서 구매처 선택은 삭제 |
| 3 | 아일리 각설탕 전달 → 톰 올드패션드 제조·제공 → 삼호 등장·갈등·루나 선택 → 삼호 맥주 → 두 사람 퇴장 → 테라스·유나 회상 |

게임 시작부터 0일차 첫 바 입장까지의 도입·출근은 유지한다. 이후 2026-11-03에는 별도 [외부 원고](https://app.notion.com/p/4071612298dc8078bfe4c1a003995248)를 기준으로 외부 NPC·상점·부비·수리·갱단·강제 사건·주변 대사·테라스·회상의 텍스트를 최신화했다. **실제 와일드 독은 갱단, 비터스는 시바견**이라는 획득 경로와 지급·수리 연출·등장 조건은 유지한다. 신규 NPC 두 명은 웹 대사를 노션 34·35번으로 기록했다.

바 선택지는 기존 바 대화 실행기를 사용하며 직전 대사를 추가 표시하지 않는다. 2026-11-03 외부 노션 원고 반영 후 2일차 테라스는 선택지 없는 13줄 순차 대화다. 크리스와 대화 → 12번째 대사 뒤 조니 회상 → 테라스 복귀 순서이며, 이전 `ch_night2_1` 재료 출처 선택은 연결하지 않는다. 외부 선택 UI의 직전 말풍선 유지·입력 보호 기능은 다른 선택형 NPC에서 계속 사용한다.

테라스 외벽의 새는 모두 원본 시트와 같은 **오른쪽 방향**을 바라본다. 발이 닿는 위치는 방향과 무관하게 유지한다. 0일차 위쪽 왼편 까마귀 한 마리·아래쪽 두 마리, 1일차 아래쪽 까마귀 두 마리와 그 사이 비둘기 한 마리, 2일차 위쪽 왼편 비둘기 두 마리·위쪽 오른편 및 아래쪽 왼편 까마귀로 배치한다. 1일차 비둘기만 세 번째 대사를 넘긴 뒤 화면 오른쪽 아래에서 들어와 하단을 따라 왼쪽으로 완만하게 휘어 이동한 후 2.8초에 걸쳐 기존 자리로 착지하고 대기 애니메이션을 시작한다. 타이핑 완료 입력은 대사 진행으로 세지 않으며, 옵션 복귀·대사 교체로 착지를 다시 시작하지 않는다. 제공된 시트는 대기 동작이므로 상승·착지 경로에 이어 원본 대기 프레임을 재생한다. 새는 건물과 같은 카메라 이동 및 빗물 굴절을 적용한다.

새의 공통 시트·발 원점·착지 경로·환경 시계·거리 날씨 배치·레이어 및 전용 검사는 [까마귀·비둘기 구현](../architecture/ambient-birds.md)에 모았다. 대화/연출 중 입력 제한은 [조작 잠금 계약](input-locks.md)을 따른다.

검증: `test-kihyun-story.cjs`, `test-kihyun-story-ui.cjs`. 본편 주문·코스터·제조·분기 양쪽·팁/이름/칩/각설탕 및 테라스 회상 복귀를 확인한다.

### 일차 전환 · 명언과 Day 숫자

일차 전환의 명언은 별도 화면 설정이며, 바/테라스 대사 CSV에 삽입하는 행이 아니다.

`bar-playtest/src/features/campaign/day-transition.js`의 `quotes`가 명언·저자·수동 줄바꿈(`\n`) 원본이며 `timing`이 연출 시간 원본이다. 0→1일차는 니체 『우상의 황혼』, 1→2일차는 스피노자 『에티카』, 2→3일차는 니체 『인간적인 너무나 인간적인』의 사용자 지정 문구를 그대로 표시한다. 3일차 마감은 기존 엔딩이며 3→4 명언 전환을 새로 만들지 않는다. 타이핑/음성/말풍선/대화 기록 대상이 아니다.

| 전환 시작부터 | 표시 / 처리 |
| --- | --- |
| 0~0.65초 | 이전 장면에서 검게 암전. 아래 게임 입력 차단 |
| 0.65~2.15초 | 완전한 검은 화면에서 1.5초 대기. 명언·저자·Day 모두 숨김 |
| 2.15~2.65초 | 중앙 명언이 12px 아래에서 올라오며 페이드 인 |
| 2.45~3.15초 | 저자가 10px 아래에서 올라오며 조금 느리게 페이드 인 |
| 3.15~7.15초 | 명언·저자가 모두 보이는 상태로 4초 유지 |
| 7.15~8.00초 | 명언·저자 페이드 아웃. 동시에 현재 `Day N`이 0.3초 동안 페이드 인. 숫자는 아직 고정 |
| 8.00~8.65초 | 명언이 완전히 사라진 뒤 기존 숫자 롤 연출로 N→N+1 |
| 8.70초 | 다음 날 리소스·기상 장면 준비를 한 번 실행. 실제 일차 변경은 기존 `day-flow.js` 콜백이 담당 |
| 9.45~9.75초 | Day 글자 페이드 아웃 |
| 9.85초 이후 | 준비 완료까지 검은 화면 유지. 완료 후 0.9초 동안 다음 장면 공개; 정상 준비 시 전체 약 10.75초 |

명언과 저자는 최초 적용 크기에서 각각 15% 축소했다. 명언 `clamp(15.3px,1.7vw,22.1px)`, 저자 명언의 75%이며, 중앙 정렬·줄바꿈·Day 숫자 크기와 다른 대화 폰트는 유지한다. `blankHold`는 암전 완료 후 첫 명언까지의 대기 시간이다.

`dayTransition.time`으로 모든 텍스트 연출을 계산해 숨김 탭 자동 정지와 재개가 일치한다. E/Enter/Space/Esc로 건너뛰지 않으며, 중복 시작·준비 결과의 뒤늦은 완료·취소·실패/재시도는 기존 전환 소유권 검사를 유지한다. 저감 모션에서는 명언·저자의 위로 이동만 생략하고 읽는 시간은 유지한다. 문구가 없는 임의 일차 조합에는 예전 숫자 전환만 표시한다.

검수: **리소스 확인 → 외부 → UI / 이벤트 테스트 → 일차 전환 / 명언 · Day 숫자 → 표시 상태**에서 0→1 / 1→2 / 2→3을 고른다. 실행 중 상태 선택과 다시 실행도 가능하다. 외부 연출/이펙트와 검은 배경 항목에도 같은 세 선택지를 제공한다. 검수는 실제 본편 일차를 증가시키지 않는다. 검증은 `test-day-quotes-ui.cjs`이며 단위/화면 배치, 느린 준비, 취소/재시도와 검수 옵션을 포함한다.

### 데이터 추적

1. `story/scenes.csv`의 실제 `day / phase / seq / when`과 본편 세션 필터로 진입 장면을 찾는다.
2. 그 장면의 자식 `steps`를 따라간다. `say`뿐 아니라 입장, 선택, 주문, 제조 대기, 캠페인 위임 단계를 함께 읽는다.
3. 선택의 `goto`, 주문의 `arg`, `campaign_*` 위임은 각 실행 담당까지 추적한다. 대사 목록만으로 플레이 순서를 추측하지 않는다.
4. 정산 확정 후 퇴근 carry로 이어지고 집 휴식에서 `playSleepScenes`를 호출한다.
5. 밤 장면 키는 0일차 `night0`, 1일차 `night1`, 2일차 `night2`, 3일차 `ending`이다. 부비 첫 반응이 있으면 그 앞에 들어간다.
6. `workshop`은 본편에서 제외되어 있다. 원본 CSV·검수 카드가 남아 있어도 휴식 뒤 연결하지 않는다.

테라스 최초 진입은 0~3일차 공통으로 암전/로딩 후 페이드 인(1.8초)과 가로 카메라 연출(6.8초)을 함께 시작한다. 0.7초 대기 → 5.6초 이동 → 0.5초 정착 뒤 첫 대사와 입력을 연다. 이동은 엔진 배치 위에 일시적인 160px→0px 가로 오프셋만 더하며 최종 `CM_Terrace`, 캐릭터·난간 좌표, 배율은 바꾸지 않는다. 다음 대사·설정 복귀·회상 복귀에서는 재시작하지 않는다. 동작 줄이기 설정에서는 이동만 생략한다.
