# 데이터·로딩·경로 계약

[구조 안내](README.md)에서 필요한 기능만 찾아 읽으세요. 게임 동작의 기준은 [본편 규칙](../gameplay/README.md)이며, 이 문서는 구현 위치를 설명합니다.

## 데이터와 로딩 경로

CSV의 소유권·메타데이터·생성 흐름·실제 대화 예제·수정 방법은 [데이터와 대화 연결](../gameplay/data-and-dialogue.md)에 통합했습니다. 조회 화면은 `bar-playtest/data-review.html`이며 생성 검사는 `node tools/build-shared-data.cjs`, 수정 후 생성은 `--write`입니다. 웹 저장소가 원본을 소유하며 엔진 자동 복사/역수입은 하지 않습니다.

초기 마이그레이션 백업 `artifacts/shared-data-backup/`은 로컬 전용으로 버전 관리 대상이 아닙니다. 초기 재수입과 구형 생성 도구로 최신 데이터를 덮어쓰지 않습니다. `data/runtime/game-data.js`와 `campaign-data.js`는 직접 편집하지 않습니다.

HTML·자원 경로 계약:

1. `index.html`의 CSS/JS 순서는 기능 의존성과 CSS 우선순위의 일부입니다. 정리 전 순서를 보존합니다.
2. 브라우저 JS에서 `assets/...`는 **페이지 주소** 기준입니다. 파일을 `src/` 안에 옮겼다고 모든 이미지에 `../../../`를 붙이면 안 됩니다.
3. CSS `url(...)`은 **CSS 파일 위치** 기준입니다. 공유 스타일을 다른 페이지에서 로드해도 같은 리소스에 도달해야 합니다.
4. 오디오와 말풍선의 `document.currentScript` 기반 URL은 본편 폴더를 명시적으로 계산합니다.
5. `src/cinema/studio-player.js`는 `cutscene-studio/src/`의 모듈을 동적으로 불러오고, 편집기 원본 에셋은 편집기 페이지 기준으로 해석합니다.
6. 기존 공개 HTML 경로·쿼리, `localStorage`/IndexedDB 키, 이야기/아이템/캐릭터 ID는 변경하지 않습니다.

## 공통 리소스 로딩 표시

`src/shared/ui/loading-screen.css`가 본편 로딩, 외부 공간 로딩, 바 출입문 아트 준비 전의 공통 표시를 소유합니다. 검은 화면 중앙에 비둘기 Idle, 그 아래 `Loading`을 세로로 묶어 중앙 정렬합니다. 빨간 박스나 별도 테두리는 표시하지 않습니다.

- 비둘기는 기존 `assets/9_ArtResources/01.Characters/02.Outside/09.StreetNPC/Idle/Pigeon_idle.png` 원본을 사용합니다. 12프레임·6 FPS·2초 반복, crop 17×14를 4.2배(71.4×58.8 CSS px)로 표시합니다. 최초 미리보기보다 가로·세로 각각 30% 축소했으며 `--loading-bird-scale`로 배율을 조정합니다. `index.html`에서 작은 시트를 우선 preload합니다.
- 글자는 기존 스타더스트 Regular(`LunaPixel` / `--font-dialogue`) 22px, 자간 0입니다. 비둘기와 간격은 16px이고 전체 묶음을 중앙 정렬합니다. 보이지 않는 점 네 글자로 실제 폰트 폭을 확보하므로 점 개수가 바뀌어도 정렬이 흔들리지 않습니다.
- 큰 게임 리소스나 게임 tick을 기다리지 않도록 CSS만으로 재생합니다. `bird-sprites.js`의 셀 129×138, crop (55,101,17,14)와 같은 수치를 CSS에 사용하며, 변경 시 `test-loading-pigeon-ui.cjs`로 프레임 위치 일치를 검사합니다.
- 점은 **없음 → . → .. → ... → .... → 없음**, 단계당 **0.1초**, 한 주기 **0.5초**입니다. 점 네 개의 폭을 확보해 글자·비둘기 위치가 흔들리지 않게 합니다. 접근성 상태 문구는 `로딩 중`으로 고정합니다.
- 로딩 진행률 갱신은 DOM/애니메이션을 재시작하지 않습니다. 로딩 중 게임 입력·게임 시계가 멈춰 있어도 비둘기와 점은 계속 재생합니다. 실제 준비 완료 시 기존 흐름으로 전환하며, 실패 시에는 기존 오류/재시도 화면을 표시합니다. 리소스 누락을 정상 완료로 처리하지 않습니다.
- 출입문 아트 준비 이후의 문 연출, 스토리 암전, 컷씬은 이 표시로 대체하지 않습니다. 환경 속 새의 일시정지/저감 모션 규칙과 별개의 로딩 전용 CSS 애니메이션입니다.

검증: `bar-playtest/tests/test-loading-pigeon-ui.cjs` (프레임 crop, 점 주기, 리사이즈 중앙 정렬, 진행 갱신, 세 로딩 경로, 게임 정지 중 재생, 완료 후 제거).
