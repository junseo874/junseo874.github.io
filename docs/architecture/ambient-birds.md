# 까마귀·비둘기 구현

확인일: 2026-11-01. 현재 본편의 환경 연출이다. 상호작용 대상·충돌체·보상·새로운 조작 잠금은 없다. [사건 흐름](../gameplay/events.md)과 [조작 잠금](../gameplay/input-locks.md)을 함께 본다.

## 소유권과 로딩

경로는 `bar-playtest/` 기준이다.

| 담당 | 파일 / 공개 객체 |
| --- | --- |
| 공통 이미지·셀·crop·프레임 계산 | `data/presentation/bird-sprites.js` / `LunaBirdSprites` |
| 테라스 일차별 배치·비둘기 착지 상태 | `src/features/campaign/terrace-birds.js` / `LunaTerraceBirds` |

| 거리 일곱 마리·날씨·건물 좌표 변환 | `src/features/outside/outside-corridor-birds.js` / `LunaCorridorBirds` |

`index.html`은 공통 메타데이터 → 테라스 → 거리 모듈 순서로 로드한다. 거리 모듈은 **테라스 실행기에 의존하지 않는다**. 테라스의 `assets/sheet/crops` 공개 속성은 호환 참조로 남아 있지만 설정 원본은 공통 파일 한 곳이다. HTML 순서 변경 시 `docs/architecture/runtime-contract.json`도 갱신한다.

PNG는 `assets/9_ArtResources/01.Characters/02.Outside/09.StreetNPC/Idle/Crow_idle.png`, `pigeon-idle.png`이며 원본 1548×138을 유지한다. 폴더명에 terrace가 있어도 두 공간 공용이다. 테라스는 `prepare()`에서 decode를 기다리고, 거리는 `apply()`가 `corridor-crow/pigeon` 에셋을 등록해 기존 로더로 준비한다. 사전 로딩 목록과 리소스 검수도 함께 유지한다.

비둘기 원본은 [공통 리소스 로딩 화면](loading.md#공통-리소스-로딩-표시)에도 사용한다. 로딩 표시는 게임 준비 전부터 보여야 하므로 동일한 crop/6 FPS를 CSS로 재생하며, 환경 속 새와 달리 게임 시계가 멈춰도 계속 움직인다. 시트 규격 변경 시 로딩 CSS와 해당 회귀 검사도 함께 확인한다.

## 프레임·발 기준

- 가로 12프레임, 셀 129×138, **6 FPS = 2초 주기**. 사람 NPC의 0.75초 주기와 별도다.
- 까마귀 crop `(52,98,24,17)`, 발 X=64. 비둘기 `(55,101,17,14)`, 발 X=66. 두 시트의 알파 발끝은 모든 프레임에서 원본 행 114다.
- 셀 전체의 투명 여백을 발/머리 기준으로 쓰지 않는다. crop 하단을 착지 좌표에 고정해 프레임마다 발이 움직이지 않게 한다.
- 원본은 오른쪽 방향이며 현재 모두 오른쪽이다. 좌우 방향을 바꿀 때 이미지만 뒤집고 발 원점은 유지한다.
- `prefers-reduced-motion`이면 프레임 0, 테라스 도착은 즉시 착지 상태. 일반 FPS 감소와 혼동하지 않는다.

## 테라스

`layouts`의 좌표는 원본 480×270 합성 화면 기준 `[종류, 발X, 발Y, 방향, 나중에등장]`이다. 벽 윗면 92/260행에 1px 겹친 Y=93/261을 사용한다.

| 일차 | 기본 배치 | 늦게 등장하는 새 |
| --- | --- | --- |
| 0 | 까마귀 (78,93), (137,261), (194,261) | 없음 |
| 1 | 까마귀 (142,261), (178,261) | 비둘기 (159,261) |
| 2 | 비둘기 (81,93), (101,93), 까마귀 (199,93), (88,261) | 없음 |
| 그 외 | 없음 | 없음 |

1일차 비둘기는 `dialog.rows`에서 **이미 넘어간 발화 행 3개**를 센 뒤 등장한다. text가 있으며 type이 없거나 say인 행만 센다. 타이핑만 완성한 입력은 세지 않는다. 특정 대사 ID나 CSV 애니메이션 트리거가 아니므로 앞부분에 대사를 추가하면 도착 타이밍도 그 세 번째 발화 기준으로 바뀐다.

`dialog.terraceBirds.arrivalAt`에 시작 시각을 한 번 기록한다. 기준 시계는 `dialog.terraceTime`이고 DOM 생성 시간/줄별 타이핑 시간/현실 시간이 아니다. 대사와 선택지 중에도 진행하고 옵션에서는 멈춘다. 화면을 다시 그리거나 대사를 넘겨도 재시작하지 않는다. 새 대화를 begin할 때만 초기화한다.

현재 도착은 총 **2.8초**다. 최종 발 위치 기준 (+227,+23), 즉 화면 오른쪽 아래 (386,284)에서 출발해 하단을 따라 왼쪽으로 완만하게 휘어 (159,261)에 착지한다. `arrival.curves`의 2개 3차 베지어 곡선과 smoothstep 시간 보간을 사용하며 중간 연결점 오프셋은 (+124,-7)이다. 방향은 이동 중에도 현재 원본의 오른쪽을 유지한다. 제공된 Idle만 사용하므로 비행 중 프레임 0, 착지 후 6 FPS 대기다. 기존 새들의 시작 위상은 인덱스당 0.47초 분산한다. 실제 비행 시트가 구현되어 있다고 전달하지 않는다.

테라스 새 canvas는 건물과 같은 카메라 변환을 적용한다. 빗물 굴절용 합성에도 같은 poses를 그린다. crop canvas는 nearest-neighbor 4배 캐시로 만들고 매 프레임 재생성하지 않는다. 이미지별 프레임 캐시와 canvas별 paint 캐시는 WeakMap이며, 장면 진행 상태는 캐시에 저장하지 않는다.

## 거리 윗벽

집 앞 주거 건물 `residence-building`의 원본 `area_A_foreground_building.png` 기준 발 X는 `517,532 / 600,618,642 / 699,723`, Y는321이다. 왼쪽 두 마리·가운데 세 마리·오른쪽 두 마리로 모으며, 왼쪽 두 마리의 발 간격은 15px, 가운데는 18px·24px로 한쪽만 더 가깝고 오른쪽은 24px를 유지한다. 플레이어 보행 바닥이 아니라 **건물 윗벽 턱**에 일곱 마리가 앉는다. 건물 위치·scale·PPU·pivot 및 parallax 변환을 통해 월드 좌표로 바꾼다. 카메라 이동에 맞춰 새 좌표를 따로 보정하거나 재추첨하지 않는다.

`LunaOutsideRain.wet(model)`가 참이면 전부 까마귀, 아니면 전부 비둘기다. 일차별 별도 날씨표를 새 코드 안에 복사하지 않는다. street이고 건물이 active인 경우만 렌더하며 home/QA에는 없다. 캐릭터 이벤트와 무관한 환경 연출이다.

시계는 `model.time`, 위상은 인덱스당 0.37초다. pause 시 멈추고 일반 대화 때는 계속된다. 이미지 조사 중에도 model.time은 진행한다. 건물 직후, 근경 철골/난간·비/후처리 이전에 그려 같은 가림과 화면 효과를 받는다.

## 변경·검증

- 종류·원본 교체: 공통 `assets/sheet/crops` → 로딩/검수 등록 → 발끝 전체 프레임 검사.

- `test-terrace-birds-ui.cjs`: 원본 규격/발끝, 0~2일차, 세 줄 진행, 상승·착지·대기, 설정 복귀, 같은 카메라 변환/빗물 합성, 리사이즈.
- `test-corridor-birds-ui.cjs`: 0~3일차 출퇴근 8종 날씨, 고정 발 위치/간격/방향, 프레임 변화, 건물 변환 추종, home/QA 제외.

엔진에서는 이 좌표계를 그대로 복제할 필요 없이 동일 벽 접점·대사 진행 시점·레이어·시간 소유권을 맞춘다. 새가 도착할 때 별도 대화 잠금이나 상태 플래그 보상을 추가하지 않는다.
