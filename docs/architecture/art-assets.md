# 실행 리소스

## 공통 원본 경로 (2026-11-01)

공통 그래픽은 `assets/9_ArtResources/` 아래에 프로젝트 상위 `9_ArtResources/`의 **상대 폴더·파일명·대소문자 그대로** 둡니다. 원본에 있는 공백·밑줄·철자도 고치지 않습니다. 이 규칙은 공통 그래픽에 한해 소문자 kebab-case 코드 파일 규칙보다 우선합니다.

- `01.Characters`: 바 인물·일반 손님 파츠·외부 인물·새 시트
- `02.Environments`: 바·거리·집·테라스·배경
- `03.Crafting`: 재료·도구·칵테일·빈 잔·제조 원본
- `04.Cutscenes`: 제공 컷씬 시트
- `05.UI`: 말풍선·프로필·서비스 패널·타이틀·기믹 UI
- `0_Dummy_Assets`: 원본 폴더에서 더미로 분류된 현재 사용 이미지

442개 기존 웹 경로를 429개 원본 대응 경로로 통합했습니다(소개 페이지·컷씬 파일 4개 포함). 동일 바이트 또는 동일 크기·RGBA 픽셀로 대응을 확인했고 **이동 전 웹 파일의 바이트를 보존**했습니다. 같은 그림의 Default/Talk·감정 폴더는 현재 역할에 맞춰 선택했습니다. 이미지 교체, 리사이즈, 프레임 변경, 엔진/드라이브 수정은 하지 않았습니다.

대응표·해시: [`art-resource-paths.json`](art-resource-paths.json). `from`은 이전 경로 기록이고 `to`가 현재 경로입니다. 캐릭터·아이템·리소스 ID는 그대로입니다. 별도 리다이렉트나 옛 파일 복사본은 두지 않습니다.

웹 생성 UI 조각·커서·생성 광고는 아래의 웹 로컬 생성 리소스 규칙을 따릅니다. 그 밖의 튜토리얼·참고 캡처·효과 마스크, 원본과 내용이 다른 버전은 기존 용도 폴더에 유지합니다. 이름이 비슷하다는 이유만으로 다른 그림을 같은 원본이라고 취급하지 않습니다. 특히 톰의 기존 Idle 몸통은 제공 원본과 달라 기존 웹 파일을 유지합니다. 폰트·음원은 이번 그래픽 이름 정리 대상이 아닙니다.

### 추가·교체와 검증

1. 공통 리소스는 원본 상대 경로를 그대로 복사하고 필요한 파일만 가져옵니다. 전체 원본/Legacy 폴더를 무조건 가져오지 않습니다.
2. 등록부의 `src`, CSS URL, 파일명을 조합하는 JS, 리소스 추출 목록을 함께 변경합니다. 파일 경로 때문에 게임 ID를 바꾸지 않습니다.
3. `node tools/build-preload-manifest.cjs --write` 및 `node bar-playtest/tools/build_resource_extraction_catalog.cjs`를 실행합니다. 사전 로딩은 대응표의 이전 용도별 그룹을 보존하며 외부 전용 이미지를 일괄 로딩하지 않습니다.
4. `node tools/check-art-resource-paths.cjs`, `node tools/check-site.cjs`, `node tools/run-tests.cjs smoke`와 리소스 화면 검사를 실행합니다. 실제 원본 교체 시 대응표의 해시도 검토 후 갱신합니다.

아래 표는 웹 전용/미대응 파일이 남는 기존 용도 폴더 안내입니다. 공통 파일은 위 원본 경로를 사용합니다.

| 폴더 | 용도 |
| --- | --- |
| `audio/music/` | BGM |
| `audio/effects/` | 효과음·대사·거리 환경음, 출처/라이선스 포함 |
| `backgrounds/bar/`, `campaign/`, `terrace/` | 장면별 배경 |
| `outside/` | Unity 외부/집 장면의 원본 스프라이트 |
| `characters/` | 인물별 시트, 일반 손님 파츠, 표정 |
| `items/` | 재료·병·잔·도구 |
| `cocktails/` | 칵테일 정적 이미지와 완성 이미지 |
| `tutorials/` | 조작·제조 설명용 캡처 |
| `ui/` | 공통 UI, 선택지, 말풍선, 분리 조각 |
| `fonts/` | 게임 폰트 |
| `reference/` | 현재 검수 화면에서 쓰는 미리보기·내보내기 및 테스트 기준 이미지 |

## 이름과 교체 규칙

- 공통 그래픽은 위 원본 경로 규칙을 사용합니다. 과거 등록 키 기반 이름과 외부 해시 이름은 미대응 웹 전용 파일에만 남습니다.
- 프레임 번호·시트 이름은 원본 애니메이션과의 대응이 중요하므로 임의로 바꾸지 않습니다. 날짜는 최종 실행 폴더명에 붙이지 않습니다.
- 원본 크기·알파·프레임 레이아웃을 보존합니다. 배치 정리를 위해 리사이즈/재압축하지 않습니다.
- 실제 URL은 `data/runtime/` 등록 정보 또는 해당 기능 모듈에서 관리합니다. 미사용 판단에는 본편뿐 아니라 검수·컷씬·소개 페이지와 동적 파일명 조합도 포함합니다. 자동 사전 로딩 목록에 있다는 사실만으로 사용 중이라고 판단하지 않습니다.
- 새 공통 이미지는 `9_ArtResources/` 원본 상대 경로에, 웹 전용 이미지는 기존 용도 폴더에 추가하고 등록부·관련 검수 항목을 함께 갱신합니다. `assets/` 루트에 파일을 다시 쌓지 않습니다.
- 음원 출처/라이선스 파일은 대응하는 음원과 함께 둡니다.

리소스 정리 이전 경로와 새 경로: `path-migrations.json`.

## 리소스 확인과 개별 추출

### 웹 로컬 생성 리소스 (2026-11-01)

최종 위치는 **이 저장소의 `bar-playtest/assets/9_ArtResources/`** 입니다. 상위 원본 폴더가 아닙니다. 추출 PNG 930개·분리 UI 18개·커서 12개·생성 광고 원화 2개에서 중복 170개를 통합하여 792개 PNG로 정리했습니다. 커서는 투명한 32×32 PNG로 변환했고 나머지는 원본 바이트·투명 여백을 유지합니다.

`bar-playtest/data/presentation/generated-art/manifest.json`은 현재 경로·이전 웹 경로·사용 화면·선택자·본체 영역·해시를 연결합니다. `sources[].src`는 이전 위치를 기록한 이력이며 실행 URL이 아닙니다. 개발자/구형 도움말 추출물은 `05.UI/99.Review`로 분리하며 검수/추출용으로 보존합니다.

웹 커서·광고·선택지 조각·튜토리얼은 해당 PNG를 직접 참조합니다. `tools/build-generated-ui-css.cjs`가 명확하게 대응하는 정적 UI 배경 69개 상태를 PNG로 연결합니다. 배치·텍스트·모서리·테두리·동적 게이지·Canvas·애니메이션은 원래 CSS/JS가 담당합니다. 남은 추출 레이어는 리소스 확인/개별 추출용이며, 모든 CSS 효과를 정지 이미지로 대체한 것은 아닙니다.

변경 후 `node tools/build-generated-ui-css.cjs --write`, `node bar-playtest/tools/build_resource_extraction_catalog.cjs`, `node tools/build-preload-manifest.cjs --write`로 목록을 갱신합니다. `node tools/check-web-generated-art.cjs`는 792개 PNG의 바이트와 파일명 규칙(`Web_` 접두사, 해상도 제외)을 검증합니다. 관리 데이터는 `data/presentation/generated-art/`에 두고 아트 폴더에는 문서를 생성하지 않습니다. 재캡처 도구는 `artifacts/ui-graphic-staging/`에만 출력하며 현재 라이브러리를 덮어쓰지 않습니다. 상위 원본·Drive·Unity에는 내보내지 않습니다.

- `resource-review.html`은 `resource-catalog.js`가 본편 등록부를 읽고, `resource-artwork.js`가 빈 잔·일반 손님 개별 파츠·타이틀·튜토리얼·외부 효과 마스크 등 합성 카드에 빠진 현재 이미지를 보완합니다. 단순히 폴더에 남아 있다는 이유로 교체 전 리소스를 재등록하지 않습니다.
- 일반 손님 파츠·빈 잔·거리 효과는 런타임 등록부에서 수집합니다. CSS/직접 경로로 사용하는 새 이미지는 `resource-artwork.js`에 사용처와 함께 추가합니다. UI 원본 조각 목록은 `node bar-playtest/tools/build_resource_extraction_catalog.cjs`로 갱신합니다.
- 여러 이미지가 합쳐진 카드는 **이미지별 원본 / 프레임 추출**에서 레이어마다 원본 시트 또는 프레임 번호를 지정해 저장합니다. 이미지가 여러 파일에 나뉜 경우 각 원본 링크를 제공합니다. 합성 PNG와 개별 레이어 PNG는 구분합니다.
- **리소스 추출**에서는 검색·분류 후 원본 PNG, 애니메이션 프레임 PNG, 선택적인 투명 여백 제거를 사용할 수 있습니다. 원본 다운로드는 재압축하지 않습니다. 프레임 추출은 원래 셀 크기·오프셋·투명도를 유지하며 화면 표시 크기로 축소하지 않습니다. 폰트·화면 참고 캡처는 이미지 추출 목록에 넣지 않습니다.
- `reference/exports`는 저장 당시의 **화면 참고 이미지**이지 원본 그래픽이 아닙니다. 최신 동작은 카드의 실제 화면 테스트로 확인하고, 변경한 화면만 `LUNA_EXPORT_MATCH`로 `tools/capture_resource_exports.cjs`를 재실행합니다.
- 회귀 검사: `node bar-playtest/tests/test-resource-current-artwork-ui.cjs`. 모든 등록 이미지 디코딩·시트 프레임 범위·원본 바이트·투명도·개별 다운로드·모바일 배치를 확인합니다.

2026-10-31 사용자 요청으로 사용하지 않는 그래픽 163개(14,157,394바이트)를 제거했습니다. 교체 전 배경·정적 제공 이미지, 옛 화면 캡처, 미등록 원본이 대상이며 현재 검수 화면과 테스트가 사용하는 파일은 유지했습니다. `reference/unmapped/`와 `serving/static/`는 더 이상 사용하지 않습니다. 이전 경로 이동표는 당시 기록이며 삭제된 파일의 현재 존재를 보장하지 않습니다. 이미지 원본은 Git 이력에서 복구할 수 있습니다.
