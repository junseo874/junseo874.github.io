- 2,404개 코드·테스트·문서·리소스 파일을 기능/용도별 위치로 이동했습니다. 기존 본편과 공개 HTML 주소는 유지했습니다.

- 정적 및 동적 로딩 경로, CSS 자원 경로, CommonJS 테스트 경로, 가져오기/캡처/카탈로그 도구의 경로를 함께 갱신했습니다.
- 공유 커서는 여러 페이지에서 CSS 변수를 사용할 때 상대 URL이 달라지는 것을 막기 위해 파일 위치에서 절대 URL을 계산하는 작은 초기화 모듈을 추가했습니다. 커서 그림과 핫스폿은 동일합니다.

## 기존 실패와 검증 한계

`test_core.cjs`의 10개 실패는 정리 전과 후 모두 동일합니다(24개 그룹 통과). 예전 해금/입력/이야기 진행 기대값이 포함된 오래된 테스트이며 이번 작업에서 기대값을 바꿔 숨기지 않았습니다.

브라우저를 동시에 여러 개 구동한 검사 중 한 번은 리사이즈 직후 설정 배율 검사에 실패했습니다. 동일 코드를 독립 실행해 370개 검사 통과를 재확인했습니다. UI/포커스 검사는 `tools/run-tests.cjs`처럼 순차 실행하는 방식을 권장합니다.

모든 과거 테스트 파일을 전부 통과했다고 주장하지 않습니다. 위 항목은 실제 실행한 범위입니다. Unity 원본과 외부 아트 폴더는 수정하지 않았습니다. 기존 미완성/프로토타입 리소스를 완성 리소스로 바꾸는 작업도 포함하지 않습니다.
