# 대사 편집기

시뮬레이터의 **대사 편집** 탭(`/bar-playtest/dialogue-editors.html`)에서 바 내부와 외부를 선택한다. `/bar-playtest/dialogue-editor.html`은 기본 0~3일차 바 대본 7개와 사용자가 등록한 새 일차를, `/bar-playtest/outside-dialogue-editor.html`은 CSV의 외부·테라스·회상 대본을 대화 단위로 묶어 표시한다. 새 게임의 ‘마지막 부탁’과 기상 후 크리스 통화는 별도의 오프닝 타임라인에서 재생한다. 개시바 상점은 거절·상품 확인·용돈 수령·퀴즈 정답/오답처럼 선택 후에만 재생되는 대사도 따로 편집할 수 있다. 선택지 복사본·공통 후속 대사는 원래 흐름 안에서 확인하며 신규 분기를 만들면 항목이 늘어난다. 미리보기는 본편 진행 상태를 변경하지 않는다.

## 대사를 편집하면서 이어 가기

바 내부와 외부 모두 대사 편집 화면에서 **다음 노드 편집 →**을 누르면 마지막 줄까지 재생하지 않고 이동한다. 다음 대사가 하나면 그 노드의 첫 줄을 바로 열고, 여러 갈래면 선택지·조건과 도착 대사를 보여 준다. 종료나 편집할 대사가 없는 사건은 도착지로 열리지 않는다. 이동 자체는 저장이나 게임 분기 실행이 아니다.

바 내부의 한국어 대사·주문·선택지 문구는 한 번 드래그한 뒤 **효과 묶음…**에서 여러 효과를 골라 적용할 수 있다. 선택하지 않으면 대사 전체가 대상이라고 표시한다. 묶음은 한 번에 되돌릴 수 있고, 개별 효과를 눌러도 같은 구절이 계속 선택된다. 다른 줄에서도 **직전 조합 불러오기**로 방금 쓴 효과들을 다시 고를 수 있다. **색상 수정** 옆의 구절을 누르면 그 구절의 기존 색상으로 팔레트가 열린다. 중첩된 색과 다른 효과는 유지되며, 이름·주문 등 공통 색상을 바꿔도 다른 대사에는 영향을 주지 않는다.

## 빈 캔버스에서 독립 노드 만들기

플로우 차트의 **빈 곳에서 우클릭 → 노드 종류 검색 → 생성**한다. 마우스 없이도 **＋ 노드 생성**으로 같은 메뉴를 열 수 있다. 기존 카드 위에서 우클릭하면 그 카드의 편집 메뉴가 열린다. 카드를 옮기는 것과 대화 순서를 바꾸는 것은 별개다. 새 노드는 선을 꽂기 전에는 본편을 바꾸지 않는다.

- **바 내부:** 대사, 선택지, 조건 분기, 손님 입장·퇴장, 코스터, 주문→제조→제공, 빈잔, 상태 변경, 튜토리얼, 영업 종료를 만들 수 있다. 선택지는 응답마다, 조건은 **조건 충족 / 그 외**에 각각 연결한다. 서로 다른 응답이 같은 대사로 합류해도 된다. 손님·좌석과 코스터가 필요한 서비스는 원래 순서를 지켜야 한다. 독립 주문 묶음의 시작은 주문, 나가는 지점은 제공이다.
- **외부 거리·집:** 왼쪽에서 인물이나 집 오브젝트를 고르고 대화, 반복 대화, 선택지, 조건 분기, 공통 합류, 플래그 변경, 사건 알림을 만든다. **다음 노드**는 같은 대화에서 바로 이어지고, **↻ 다시 말을 걸 때**는 다음 상호작용의 시작을 바꾼다. 예를 들어 신문 NPC의 이 핀을 반복 대화에 연결해도 첫 방문의 질문·정답/오답·기어는 그대로다. 첫 대화 끝에 말을 더 붙일 때는 보상과 작별 인사가 끝나는 공통 노드의 **다음 노드**를 쓴다. 실제로 재방문하는 입구가 없는 일회성 사건, 선택 입력을 받지 않는 자동 주변 대화·컷씬에는 임의의 재방문/선택 입구를 만들지 않는다.
- **연결과 저장:** 출력 핀을 원하는 입력으로 끈다. 출력 하나를 다른 곳에 다시 꽂으면 이전 선은 교체되고, 입력 하나는 여러 경로에서 받을 수 있다. 노드나 핀의 우클릭 메뉴에서 직접 만든 노드를 삭제하거나 연결을 해제할 수 있다. 실행 취소 후에도 경로가 복구된다. 웹 로컬 저장은 실제 CSV에 기록하며, 바는 기존 조건·효과와 선택지 그룹을, 외부는 수동 장면·기본 이동(`goto`)·선택 결과(`result_steps`)를 사용한다. 새 CSV 열이나 엔진 명령은 없다. 배치 좌표는 브라우저 편집 환경에만 보관한다.

## 바 내부 · 플로우 차트

**대사 편집 → 바 내부**에서 일차와 장면을 고른다. 차트는 CSV를 읽어서 그린 것이며 별도의 그래프 파일이 아니다. 입장·퇴장에 따라 손님 구성이 바뀌고, 같은 조건과 좌석의 연속 대사는 한 노드로 묶인다. 선은 선택지의 이동 장면(`goto`), 선택 효과(`effects`), 뒤따르는 행의 실행 조건(`when`)에서 계산한다. 각 출력 핀에는 직접 연결된 첫 목적지만 표시한다. 도착 줄의 실행 조건은 그대로 적용된다. 오른쪽 ‘다음 노드 연결’을 누르면 해당 노드나 도착 장면으로 이동한다.

- **오른쪽 디테일:** 기본은 전체 속성을 표시한다. 카테고리 버튼이나 속성 검색으로 주문·선택지·분기·구성을 좁혀 보고, 제목 왼쪽의 색으로 구분한다. 대사/진행 줄은 아래쪽, 그 뒤는 **다음 노드 추가 → 핀 배치** 순서다.
- **주문한 술 변경:** 주문 노드뿐 아니라 제조·제공 노드의 **주문 → 주문한 술**에서도 자유 주문 또는 그날 사용 가능한 칵테일을 고른다. 같은 장면의 다른 노드에서는 **원본 주문 줄**을 선택한다. 여러 분기를 거쳐 주문을 하나로 특정할 수 없을 때도 줄을 먼저 고른다. 바뀌는 것은 그 주문의 기존 `arg` 값뿐이다. 제조·제공 행과 대사 문구는 그대로이며, 대사 안에서 칵테일 이름을 직접 말하면 별도로 수정한다.
- **노드 미리보기:** 미리보기를 열거나 다른 노드로 이동하면 첫 줄(대사 목록에서 열면 선택한 줄)을 완성된 문장으로 표시하고 기다린다. **자동 재생**을 눌러야 현재 줄부터 타이핑하며 이어지고 노드 끝에서 멈춘다. 자동 재생 없이도 줄을 직접 넘길 수 있다. **다음 노드 미리보기 →**를 눌러야 다음 노드로 간다. 첫 줄이나 중간 줄, 일시정지 중에도 이 버튼으로 남은 대사를 건너뛸 수 있다. 연결이 하나면 즉시 이동하고, 여러 개면 **이어 볼 분기 선택**에서 선택지 문구·조건과 도착 줄을 보고 한 경로를 누른다. 바 화면에서 미리 고른 답도 이 목록에서 바꿀 수 있다. 주문 일치·불일치나 제조 등급 등 현재와 다른 결과는 **조건을 가정한 미리보기**로 표시한다. 선택 창을 닫으면 이동하지 않는다. 조건·선택 효과·연결 핀·다른 장면으로의 이동은 미저장 대본과 미리보기 조건을 사용한다. 마지막에는 다음 버튼이 사라진다. 조건부 노드는 그 분기에 진입한 것으로 미리 본다. 선택지는 입력을 기다리고 제조·코스터는 기존 편집기처럼 결과 상태만 보여준다. 실제 플레이 기록은 바꾸지 않는다.
- **노드 편집:** 해당 묶음만 줄 목록에 표시한다. 기존 편집기의 텍스트 효과, 표정, 선택지, 되돌리기를 그대로 사용한다. ‘대사 편집기’로 돌아가면 장면 전체를 볼 수 있다.
- **선택 분기:** 대화 뒤에 선택지 노드를 추가하고 문구를 편집한다. ‘조건부 대사’는 같은 장면에 `say`를 추가하며, 선택 결과는 기존 `flag.* = true/false`와 `when`으로 연결한다. 이미 다른 장면으로 향하는 옵션은 해당 장면에서 편집한다.
- **제공 결과:** 제공 노드에서 주문 일치 여부, 제조 등급 또는 최종 등급에 따른 응답을 추가한다. 조건이 겹치면 CSV 순서대로 둘 다 재생된다. 특정 칵테일 ID는 현재 엔진의 대사 조건이 아니므로 제공하지 않는다.
- **저장:** 플로우 차트와 대사 편집기는 같은 미저장 변경을 공유한다. 로컬은 변경 내역 확인 뒤 CSV와 본편 데이터를 함께 저장한다. GitHub Pages는 ZIP으로 내보낸다. 노드 좌표·미리보기 상태는 게임에 저장하지 않는다.

### 장면을 나누고 편집하기

왼쪽의 **일차 → 대본 → 편집 장면** 순서로 찾는다. 노드가 10개 이하면 자동으로 나누지 않는다. 더 길면 10개 전후의 입장·퇴장을 경계로 삼고 인물 변화가 없으면 10개를 넘겨도 한 대화를 유지한다. 예를 들어 0일차 첫 대본은 크리스와 포트 등장으로 나뉜다. 편집 장면은 화면에서 다루는 단위다. 경계에서 카메라·주문·좌석·플래그·제조 등급이 초기화되거나 게임 재생이 끊기지 않는다.

- 노드 우클릭(키보드: Shift+F10) → **이 노드부터 다음 장면으로 분리** → 이름을 입력한다. 선택한 노드부터 현재 편집 장면 끝까지가 새 장면으로 이동한다. 옮길 개수와 연결선 수를 먼저 표시한다. 현재 장면의 첫 노드는 이름만 바꿀 수 있다. 장면 합치기, 자동 구분 복원, 실행 취소/다시 실행도 가능하다.
- 수동으로 정한 장면 이름·시작점은 변경 내역을 거쳐 기존 웹 연결 파일 `web-views.json`에 저장한다. 다른 기기에서도 같은 구분으로 열린다. 이 목록은 편집기만 읽는다. Unity의 씬 ID나 대사 CSV를 조각내지 않는다. 경계를 넘는 선은 다음 장면 카드로 표시한다. 여러 장면에 걸쳐 직접 연결할 때는 **전체 연결 보기**를 사용한다.
- 기본 배치는 오른쪽 방향이다. 카드는 드래그로 배치하고, 빈 공간은 끌어서 이동한다. 휠은 커서 중심으로 25~300%까지 부드럽게 확대·축소한다. F는 선택 카드로 이동, Alt+방향키는 카드 이동, Esc는 연결/팝업 취소다. 카드별 핀 방향, 가로/세로 방향의 수동 배치, 아직 연결하지 않은 핀은 해당 브라우저에만 보관한다.
- 노드를 끌어서 놓으면 한 번의 이동으로 기록한다. `Ctrl+Z`(Mac: `⌘Z`)로 원위치, `Ctrl/⌘+Shift+Z`로 다시 이동한다. 대사 수정·분기 연결과 실제 작업 순서대로 되돌아간다. Alt+방향키 이동과 자동 정렬도 되돌릴 수 있다. 클릭만 하거나 드래그 중 Esc로 취소하면 기록하지 않는다. 배치를 바꿔도 CSV와 게임 진행에는 영향이 없다.
- 카드 하단 **＋ 선택지**는 실제 옵션과 출력 핀을 추가(1~4개)한다. 오른쪽에서 문구·선택 조건·효과·잠김 이유와 삭제를 관리한다. **＋ 분기 핀**을 누른 뒤 오른쪽에서 조건을 확정하고, 출력을 원하는 입력에 끌거나, 핀 편집에서 **연결 대상 다시 지정**을 누른 뒤 입력 핀을 고른다. 주문 노드에서는 자유 주문 또는 해금된 특정 술을 고른다.
- 조건 조합에서 플래그, 일차, 소지금, 호감도, 주문 일치, 제조/최종 등급을 함께 선택할 수 있다. **분기 핀**은 위에서 처음 맞는 경로 하나로 가고, **조건의 반응 대사**는 맞는 줄을 각각 재생한다. 연결은 엔진의 기존 `effect`, `when`, `effects`, 선택지 `goto`만 사용한다. 같은 장면에서 뒤로 가는 선, 필수 좌석 전환이나 제공 절차를 건너뛰는 선, 제공 전 등급 검사는 막는다. 연결을 해제하면 도착 행의 원래 조건은 유지된다.

핀·핀 이름·연결선을 클릭하거나 **다음 노드 연결 → 핀 편집**을 누르면 오른쪽에 해당 출력만 열린다. 선택지의 **선택 가능 조건**은 누르기 전에, **선택 시 값 기록**은 누른 직후에, **선택 후 이동 조건**은 그 값이 기록된 뒤에 검사한다. 값이 거짓이어도 선택 자체를 취소하지 않고 원래 대본을 계속한다. 도착 노드의 원래 조건이나 다른 선택지에는 쓰지 않는다. 대본 순서로 생긴 길은 목적지와 조건을 지정해 이 출발점 전용 연결로 만들 수 있다. 바로 다음 줄이 목적지라면 조건이 달라도 같은 줄에 도착할 수 있다. 다른 장면으로 이동하는 선택지는 선택 가능 조건을 사용한다. 같은 장면 이동 전용 조건이 남아 있으면 장면 연결로 바꿀 때 먼저 지우도록 안내한다.

**변경 적용**은 핀 한 개의 수정을 한 번에 반영한다. CSV 저장은 별도다. 연결의 조건을 바꾸더라도 도착 노드와 원래의 핀 우선순위는 유지한다. 조건을 지워 기본 경로로 바꾸면 다른 조건 분기 다음으로 정렬하며, 기본 경로가 이미 있다면 중복 생성을 막는다.

### 새 일차와 테스트

플로우 차트와 대사 편집기 왼쪽의 **← 시뮬레이터**는 편집 경로와 관계없이 개발자 시뮬레이터 탭을 연다. 직전 편집 화면으로 돌아갈 때는 브라우저 뒤로가기를 사용한다. 미리보기 닫기는 편집기를 벗어나지 않는다.

**새 일차 만들기**는 4~98 중 빈 번호로 개점 전/단골 영업 대본을 준비한다(99는 QA). **노드 추가** 또는 우클릭으로 대사, 입장/퇴장, 선택지, 코스터, 주문→제조→제공, 빈잔, 상태 변경·튜토리얼·영업 종료를 배치한다. **노드 미리보기**은 차트 위 팝업에서 노드 단위로 수동 이동하고, **바 장면 테스트**는 미저장 대본으로 실제 바의 입력과 분기를 시험한다. 후자는 저장 공간을 분리한 게임 화면이며 개점 전부터 시작하면 일반 영업을 건너뛰고 단골 영업으로 이어진다. 원하는 잔/등급을 바로 제공해 결과별 대사를 시험할 수도 있다.

기존 노드 앞뒤에 주문 묶음을 끼워 넣을 때 해당 손님이 이번 방문에서 코스터를 받는 줄이 없으면, 주문 바로 앞에 기존 코스터 제공 줄도 넣는다. 이미 원하는 위치에 넣어 두었으면 중복 추가하지 않는다. 코스터가 있어야 실제 바에서도 잔을 내려놓을 수 있다.

실제 저장 시 기존 일차 목록·바 대본·스크립트 등록부와 기존 형식의 서식 참조에 새 일차 행만 추가한다. 서버가 기준 원본에서 등록 정보를 다시 계산하고 기존 등록 변경/다른 일차 덮어쓰기를 거부한다. 새 명령이나 CSV 열은 만들지 않는다. **웹 본편 엔딩은 여전히 3일차이며 Unity의 일차 등록은 건드리지 않는다.**

관련 파일: `flow-sections.js`(구간/이름), `flow-model.js`(등장인물·대사 묶음), `flow-wiring.js`(핀과 실제 명령 간 변환), `flow-canvas.js`와 `flow-workspace-menu.js`(차트/우클릭), `line-actions.js`(행 추가·복제·종류 변경·삭제 보호), `flow-days.js`(정식 일차 등록), `session-playtest.js`(격리 플레이). `test-bar-flow-wiring.cjs`, `test-bar-day-authoring.cjs`, `test-bar-flow-editor-ui.cjs`, `test-bar-authoring-studio-ui.cjs`는 저장·재로드, 실제 분기·제공, 장면 이동을 각각 검증한다.

## 외부 편집기 · 현재 지원 범위

- **일차별 차트:** 0~3일차 탭 옆의 **출근길 / 퇴근길** 스위치는 각각 켜고 끈다. 기본은 두 시간대 모두 켜짐이며, 둘 다 끄면 목록과 차트가 비워진다. 날짜와 시간대를 한 쌍으로 판정하므로, 예를 들어 기신교 신도는 0일차에는 퇴근길에만, 1일차에는 두 시간대에 표시된다. 검색·바로가기·분기·위치 지정도 같은 범위를 사용한다. 각 조합에서 마지막으로 보던 대사를 기억하고, 주소를 복사하면 같은 필터로 열린다. 여러 시간대의 대본은 복제하지 않고 같은 원본을 편집한다. 필터 자체는 CSV와 본편을 변경하지 않는다. 보관 대본까지 보려면 **전체**에서 두 스위치를 모두 켠다.
- 새 독립 노드는 현재 탭의 날에 표시된다. **전체**에서 만들 때는 해당 장소·인물에 등록된 날 중 하나를 고른다. 연결한 뒤에는 그 노드를 실제로 호출하는 흐름의 날과 선택 조건을 따르며, 날짜 탭을 누르는 것만으로 본편이나 CSV가 바뀌지 않는다.
- 왼쪽은 NPC/장소별 흐름과 전체 본문 검색·즐겨찾기, 가운데는 검정 격자 배경의 캐릭터/말풍선 미리보기와 줄 목록, 오른쪽은 선택 행 편집이다. 흐름 간 이동 기록과 관련 흐름 바로가기, 현재 줄/연속 재생, 추가·복제·삭제·순서 이동, Ctrl/Cmd+Z/Shift+Z, 변경 비교, 버전 일치 임시 편집 복원을 제공한다.
- **기존 CSV 스키마를 확장하지 않았다.** `web-views.json`의 outside, campaign.scenes, prologue를 실제 부모·분기 ID로 역추적한다. 바의 복사본이나 웹 미사용 엔진 예시 대본을 본편 외부 대사로 표시하지 않는다. 빈 연결 장면은 목록에서 제외한다.
- `story/steps.csv`의 실제 투영 텍스트와 지원되는 화자를 저장한다. 일반 say는 같은 템플릿으로 추가/복제한다. 하위 강조 데이터·보상·기존 연출 행은 삭제/복제를 막는다. 신규 선택지 장면은 추가/삭제할 수 있으며, 삭제 시 편집기가 만든 자식 분기도 함께 정리한다.
- 선택지는 대사 목록의 해당 시점에 포함한다. 신문 NPC의 `options` 복사본, 정보 주제·상점 물품 메뉴는 왼쪽 독립 항목으로 표시하지 않는다. 신문 정답/오답 뒤 공통 합류·마무리, 신도 인사 뒤 마무리, 상점 퀴즈 설명도 이어지는 목록에서 본다. 실제로 갈라지는 분기는 별도 흐름이다.
- 본편과 같은 `LunaWorldChoices`/`world-choices.css`로 선택바·모서리·E 표시·500ms 입력 보호·불가 사유·빨간색/글리칭을 재현한다. 빈 선택지 행은 직전 대사를 유지하며 직전 대사도 없으면 말풍선을 숨긴다. 휠/키 조작은 미리보기 영역에 한정하여 편집 입력을 가로채지 않는다.
- 같은 선택지 장면에서 문구·조건·소지금만 바뀌면 기존 버튼 요소를 유지하고 내용만 갱신한다. 입력할 때마다 등장 애니메이션을 재생하거나 선택/입력 유예 시간을 초기화하지 않는다. 다른 장면으로 이동하거나 메뉴를 닫았다 다시 열면 정상적으로 등장한다.
- 불량배·정보 구매·개시바·신문 NPC·노숙자·부비·수리공·갱단·옷장의 연결 메뉴는 **1~4개 선택지 추가/삭제/순서·문구·추가 조건·불가 사유**를 저장한다. 후속 연결은 `continue`(현재 흐름 계속), `end`(대화 종료), `native:<기존 동작 ID>`, `flow:<외부 흐름 ID>`다. 새 대사 분기는 기존 `result_steps` 구조로 만들며 일반 분기는 읽은 뒤 원래 다음 줄로 합류한다. 신문 NPC의 커스텀 분기는 기존 공통 대사·기어 지급·완료 플래그 경로로 합류한다.
- 기존 동작의 가격·재고·아이템 소유·완료 검사와 보상 실행은 해당 NPC가 소유한다. 편집 조건은 여기에 AND로 추가된다. 이미 판매한 상품 등 원래 숨겨지는 동작은 별칭 선택지를 만들어도 노출하지 않는다. 삭제된 선택지 ID를 직접 호출해도 실행을 거부한다. 기존 선택지를 다른 대사 분기로 연결하면 그 선택지의 원래 구매/수리 동작 대신 지정한 대화를 실행한다.
- **미리보기 전용:** 줄별/인물별 캐릭터 시트·방향·재생 속도·보유 행동 클립, 소지금/플래그, 재료·기어·엠블럼·목표·돈 알림. 이 설정은 CSV·임시 대사 파일에 들어가지 않는다. 동일 NPC도 줄마다 다른 시트를 시험할 수 있지만 본편 변경 기능으로 오인하지 않도록 표시한다. 실제 원본 NPC Idle, 루나 Idle/Walk/Run, 삼호 Idle, 개시바 시트를 사용한다. 외부 시트가 등록되지 않은 인물은 이름과 자리표시자로 표시하며 다른 인물로 몰래 대체하지 않는다. 말풍선 스킨·마침표 타이핑은 본편 공통 모듈을 사용한다. 보상 미리보기는 진행/인벤토리를 변경하지 않는다.
- **지원 대기:** 동적 짧은 응답, 엘리베이터 메뉴, CSV 밖 TV 다큐 문구, 신규 아이템/보상 명령, 텍스트 효과 태그, 임의 타임라인/애니메이션 본편 저장. 자동 배경 대화와 캠페인 컷씬에는 플레이어 입력을 기다리는 신규 메뉴를 삽입하지 않는다. NPC별 애니메이션 실행 계약도 별도다. 도움말과 해당 항목에 제한을 표시한다.
- 외부 텍스트에는 `<shake>` 등의 효과 태그를 저장하지 않는다. 묶인 말줄임표는 `...`로 정규화한다. 영문 자동 번역은 하지 않는다.
- `characters/field_animations.csv`의 FieldAnimations는 캐릭터·동작·리소스 목록이다. 그 목록의 존재와 외부 대사 줄에서 특정 인물의 클립·유지 범위를 실행하는 기능은 별개다. 현재 편집기는 기존 `arg`의 의미를 임의로 바꾸거나 새 명령을 저장하지 않는다. 애니메이션 본편 적용은 이 실행 계약을 정한 후 연결해야 한다.

### 외부 저장·자동 반영

수리공 상황은 편집기 ‘조건 테스트 / 알림’에서 일차·소지금·인벤토리·플래그를 지정한다. 본편과 동일한 순수 조건 함수로 기어 소지, 400원 경계, 이미 결제/수리한 상태를 판정한다. 테스트는 아이템이나 돈을 소모하지 않는다.

저장 확인은 수정한 메뉴의 활성 ID/순서와 한국어 대사 행 ID 경로를 정적으로 대조한다. Unity의 일반 선택지는 비어 있지 않은 result_steps를 실행한 후 부모로 돌아가지 않는다. 신규 메뉴는 기존 `choice` 타입을 쓰며 `editor-choice`는 생성/저장하지 않는다. 경로 불일치나 확인되지 않은 C# 사건 메뉴 변경은 저장·내보내기를 차단한다(2026-11-07 엔진 계약 고정 원칙). 엔진이 CSV 옵션을 읽는 불량배·상점 인사/용돈 메뉴의 문구·조건 수정은 원래 옵션과 동작 연결을 유지하는 범위에서 허용한다. 이 검증이 Unity 실행·보상 검증을 대신하지 않는다. 신문 기본 분기에서 조건부·중간·복수 goto, 순환이나 없는 대상은 저장 오류다.

외부 저장은 같은 loopback API에 `mode: outside`로 전달한다. 대화 저장 파일은 `story/steps.csv`, `story/street_choices.csv`, `web-views.json`이다. 독립 노드를 만들거나 지울 때는 `story/scenes.csv`의 해당 수동 장면도 함께 저장한다. NPC 위치는 별도의 웹 배치 파일에만 저장한다. CSV 열/스키마 파일은 추가하지 않는다. 옵션 소유 행은 필요할 때 기존 `steps_format_62`, 신규 옵션은 `street_choices_format_02`, 신규 분기 대사는 `steps_format_30`을 사용한다. 기존 화자 이름은 웹 연결 설정에 보존한다.

`web-views.json.outsideChoiceEdits`는 선택지 부모 행 ID별 `stepId/who/active/routes`를 기록한다. **문구·조건은 CSV, 활성 순서·본편 코드 동작 연결은 이 설정**이 정본이다. 삭제한 기존 옵션의 원본/하위 대사는 다른 연결을 깨지 않도록 보관하고 `active`에서 제거한다. 신규 선택지 장면 자체의 삭제는 편집기 생성 하위 트리까지 제거한다. 새 분기의 `outside.editor/...` 참조도 함께 저장한다. 이 웹 실행 어댑터는 Unity에서 자동 실행되지 않으므로 엔진 연동 시 별도 구현이 필요하다.

서버는 범위 밖 데이터, 잘못된 부모·후속 연결, 빈/5개 이상 메뉴를 거부한다. CSV 검증·revision 충돌 검사·백업 후 실행 데이터도 함께 재생성한다. GitHub는 같은 구조의 ZIP을 내보내며 엔진·Notion·Drive는 변경하지 않는다.

`/api/dialogue-editor/runtime`의 `exterior`에 sharedStory/선택지/scenes/prologue를 담는다. live-data는 기존 NPC 모듈이 캡처한 배열의 정체성을 유지하며 내용을 갱신한다. 갱신 전에 이미 재생 중인 외부/배경/캠페인 대사의 행 배열을 분리해 현재 흐름을 보존한다. **새로 시작하는 대화 흐름/회상부터** 수정본을 사용하고, 돈·플래그·보상·완료 상태는 재실행하지 않는다. 한 상호작용 안에서도 선택 후 별도 흐름을 시작하면 그 흐름은 최신본이다. 바는 기존대로 장면 경계에서 적용한다.

외부 스튜디오의 기본 화면은 **인물 → 사건 → 플로우 차트**다. 바 내부와 같은 왼쪽 작업 레일(화면 전환·대본 선택·저장), 가운데 작업 화면, 오른쪽 디테일(속성 검색·항목 필터·속성 행)을 사용한다. 디테일의 “진행 줄”은 차트를 떠나지 않고 노드 안의 대사를 선택한다. 팝업에서는 노드 안에서만 대사가 이어진다. 선택한 답변·공통 대사·후속 대본은 **다음 노드 미리보기 →**로 한 번에 한 노드씩 이동한다. 대사가 끝나기를 기다릴 필요는 없고, 아직 답하지 않은 선택지는 먼저 고른다. 마지막 대사나 본편 전용 사건에서는 멈춘다. 왼쪽·대본 화면에서 열면 선택 중인 줄부터, 카드에서 열면 그 노드 첫 줄부터 시작하며, 닫으면 원래 편집 위치로 돌아온다. 거리, 상층 복도, 집, 소문/방송, 테라스와 회상을 분리하고 같은 NPC의 재방문·선택·공통 합류를 한 차트에 그린다. 대화 묶음(최대 6줄), 선택, 사건 신호는 각각 구분한다. 차트 카드의 제목을 끌면 배치만 바뀐다(브라우저에만 저장). 본편 순서 편집은 대본 목록에서 한다. 선택 핀을 눌러 시작 노드를 고르거나 끌어 연결한다. 이동을 바꾸려면 기존 CSV의 `result_steps/goto`로 표현돼야 하며, 거래/지급 핸들러를 다른 동작으로 조용히 바꿔치기하지 않는다. 신문 답변은 실제 이동 명령을 수정하며 공동 보상 줄을 복제하지 않는다. 새 선택에 독립 대화로 이동하는 연결은 같은 외부 데이터셋·선택 뒤에 남은 단계가 없는 경우만 저장한다. 엔진과 다른 진행은 변경 확인에서 계속 차단한다.

**위치 지정**은 실제 웹 씬 아트와 월드 좌표를 보여 준다. 바닥을 누르거나 X를 입력하고 방향키(0.01), Shift+방향키(0.1)로 조정한다. Y는 거리·복도·소파·진열대에서 인물별 발 기준을 유지한다. 두 사람이 있으면 첫 항목으로 둘을 함께 옮기거나 동행 인물만 골라 간격을 바꿀 수 있다. 서로 자리를 침범하지 않도록 대화 거리, 갱단 통행 경계, 상자와 이웃의 거리에 따라 허용 범위를 제한한다. TV·전단·테라스처럼 씬 오브젝트나 고정 연출인 경우는 이동할 NPC가 아니다. 창에서 **적용**은 편집 초안만 변경하고 **변경 내역 / 저장**이 실제 디스크에 반영한다.

좌표의 정본은 웹 전용 `bar-playtest/data/presentation/npc-placements.json`이다. 별도 저장값이 없으면 등록된 기본 위치를 쓴다. 0일차 퇴근길의 노숙자와 근처 행인은 상자 앞과 그 왼쪽이 기본이며 위치 창에서 함께 보되 독립적으로 이동한다. 신문 읽는 남자는 거리 바닥 Y를 저장하고, 본편·위치 편집기는 그 위 0.074의 좌판 보정과 오른쪽 방향을 동일하게 적용한다. 엔진 스냅샷·대사 CSV 열·게임 플래그는 변경하지 않는다. `features/outside/npc-placement.js`가 대상과 보행면·범위를, `npc-placement-runtime.js`가 동일한 이동량을 그림·상호작용·말풍선 기준·이벤트에 적용한다. 로컬 저장 시 충돌 검사와 백업을 거치고, 열려 있는 본편은 대화/사건이 끝난 안전한 시점부터 바뀐 배치를 사용한다. 배치만 저장하면 CSV나 생성 대본을 다시 쓰지 않는다. ZIP에서도 이 파일은 `data/presentation/` 아래에 있다.

**대화 미리보기**는 같은 재생기와 실제 거리 선택 UI를 독립 팝업으로 옮긴다. 처음 열거나 다음 노드로 이동하면 한 줄을 표시하고 기다린다. **자동 재생**은 현재 줄부터, **이 노드 다시 재생**은 첫 줄부터 재생한다. **현재 줄 재생**은 한 줄만 재생한다. 거리 화면에서 답을 골라도 즉시 이동하지 않는다. **다음 노드 미리보기**를 누르면 연결이 하나일 때는 바로 이동하고, 여러 개면 선택지 문구와 도착 대사가 표시된다. 거리 화면에서 누른 답과 다른 경로를 골라도 된다. 잠긴 선택지에 연결된 대사는 **잠긴 경로 미리보기**로만 열 수 있으며 실제 구매·보상은 실행하지 않는다. 대사 도중이나 일시정지 중에도 사용할 수 있다. **이 노드 다시 재생**으로 같은 노드의 첫 줄로 돌아간다. 실제 돈·아이템·플래그는 바뀌지 않는다. 고정 사건의 거래/시네마 전체를 재현하는 플레이 모드는 아니다.

소유: `outside-flow-map.js`(NPC 분류와 합류), `outside-chart.js`(시각 편집), `outside-wiring.js`(허용되는 실제 CSV 연결), `outside-placement.js`(씬 피커), `outside-model.js`(CSV 범위/역참조/검증), `outside-editor.js`/CSS(편집 UI), `outside-preview.js`(독립 검수 화면), `storage-client.js`(저장 통신), `features/outside/events/outside-authoring.js`(본편 선택지 연결). 테스트 `test-outside-dialogue-editor.cjs`와 `test-outside-dialogue-editor-ui.cjs`는 별도 임시 복사본에 실제 저장하며 운영 CSV에는 검사 문장을 쓰지 않는다.

## 사용

1. 일차를 고르고 왼쪽의 **개점 전 / 단골 영업** 버튼으로 바 대본을 바꾼다. 없는 대본의 버튼은 비활성이다. 줄을 누르면 그 앞의 입장·퇴장·표정·코스터·잔 상태를 복원하고 실제 바 화면으로 표시한다.
2. 오른쪽에서 한국어/영문, 화자, 표정, 인수, 실행 조건, 효과를 편집한다. 대사·표정·최대 4개 선택지는 즉시 미리보기에 반영된다. 추가/복제/삭제/위아래 이동, 검색, 되돌리기/다시 실행을 제공한다. 입장 좌석 수에 따라 1인/2인 카메라 구도가 실제 바와 같이 바뀐다.
3. 현재 줄 재생은 타이핑·입 움직임을 확인한다. 연속 재생은 선택지에서 멈추며, 화면의 선택지를 눌러 진행한다. 제조/코스터/튜토리얼의 실제 조작은 생략한 **편집용 재생**이다. 제조 성공을 전제로 잔 상태를 표시하며 전체 게임 플레이 테스트를 대체하지 않는다. 미리보기 조건의 돈·플래그는 CSV에 저장되지 않는다.
4. 변경 내역에서 추가·삭제·필드 값 차이를 확인하고 확정한다. 태그·CSV 구조·선택지 연결 오류가 있으면 저장/내보내기를 막는다. 원래 조건문으로 실행되지 않는 줄도 직접 선택하면 검토할 수 있으며 경고가 표시된다.

### 대본 목록의 우클릭

- 행을 우클릭하거나 키보드로 선택하고 **Shift+F10**을 누른다. 누른 행을 기준으로 앞·뒤에 대사를 추가하거나 복제·삭제·이동할 수 있고, **진행 종류 변경**에서 기존 바 명령을 선택한다. 같은 메뉴에서 현재 줄을 재생하거나 플로우 차트의 해당 노드로 이동한다.
- 종류를 바꾸기 전에 지워지는 문구·선택지를 안내한다. 선택지로 바꾸면 별도 옵션 두 개를 만들며, 선택지 줄을 복제해도 원본과 옵션을 공유하지 않는다. 마지막 참조를 지울 때만 옵션을 정리한다. 연결된 행은 먼저 연결을 해제하며, 고정 초기 배치, 연속 입장, 제조·제공 사이, 마지막 종료 위치는 보호한다. 필터나 장면 경계 너머로는 줄을 옮기지 않는다.

### 바 조건과 효과 편집

노드·선택지·핀·대사 줄·새 명령은 같은 조건 편집기를 사용한다. **조건 추가**에서 항목을 고르고 그 행에서 값을 수정한다. 예를 들어 **호감도 → 크리스 → 10 → 이상**과 **주문 일치**를 함께 두면 두 조건이 모두 맞아야 진행한다. 인물 목록은 캐릭터 표의 호감도 사용 인물만 표시한다. 선택 후 효과는 플래그 참·거짓, 소지금 더하기·빼기, 인물 호감도 변경으로 작성한다. 기존 조건은 보기만 해도 변환되지 않고, 지원 목록 밖의 기존 값은 보존한다. 편집 화면의 표시 이름은 엔진 CSV에 추가되지 않는다.

핀이나 연결선을 누르면 오른쪽에 **선택지 내용 → 선택 가능 조건 → 선택 시 값 기록 → 이동 조건 → 연결 경로**가 펼쳐진다. 일반 출력 핀에는 해당 항목만 나온다. 선택지 문구와 조건, 목적지는 **변경 적용**으로 함께 반영하며, 실제 파일 저장은 기존 **변경 내역 / 저장**에서 한다.

### 플로우 차트의 출력 연결

- 출력 핀의 원·이름이나 연결선을 우클릭하면 해당 핀 전용 메뉴가 열린다. 미연결 핀은 행 옆 휴지통, 핀 디테일의 휴지통 또는 핀에 초점을 둔 뒤 Delete로 삭제한다. 삭제한 미연결 핀은 되돌릴 수 있으며 실제 CSV에는 영향을 주지 않는다. 기존 연결은 **연결만 해제**, 선택지와 경로를 함께 지우려면 **선택지 삭제**를 사용한다. 마지막 선택지와 시스템의 기본 진행 핀은 실수로 삭제할 수 없다.
- **출력 핀 하나 = 직접 연결 한 곳.** 같은 선택지·조건을 새 목적지에 연결하면 이전 선과 건너뛰기 범위가 교체된다. 직접 연결한 목적지를 다시 누르면 변화가 없고 잘못된 연결이나 취소는 기존 선에 영향을 주지 않는다. 서로 다른 출력이 같은 입력으로 합류하는 것은 가능하다.
- 출력은 지정된 첫 노드를 보여 준다. 도착 줄의 조건이 맞지 않아 실제 재생에서 건너뛸 수 있는 후속 줄을 추가 연결처럼 그리지 않는다. 조건 조합의 공백이나 순서만 달라도 같은 출력으로 취급한다. 선택지의 다른 대본 이동과 같은 대본 노드 연결은 동시에 남지 않는다. 자기 자신·뒤에서 앞으로 가는 선, 주문 절차나 입퇴장 건너뛰기, 대본 이동 순환은 허용하지 않는다.

## 색상과 편집 단축키

대사 편집기 가운데는 미리보기와 대본 목록, 오른쪽은 선택한 줄이다. 목록에서 대사·선택지·주문/제조/제공·기타 이벤트 또는 수정한 줄만 표시할 수 있다. 검색은 화자와 대사뿐 아니라 선택지 안의 문구도 찾는다. 검색어나 필터는 표시와 수동 이동에만 영향을 주고 CSV 순서나 연속 재생은 바꾸지 않는다. **크게 보기**로 표정·효과를 확인하고, **미리보기 접기**로 대본 목록을 넓힌다. 목록에서 ↑/↓, Home/End로 이동하고 Enter로 본문을 편집한다. 입력칸 밖에서 /를 누르면 검색한다. 좁은 화면도 기본은 **함께 보기**다. 대본만 보거나 상세 편집만 크게 볼 수도 있다.

두 화면의 오른쪽은 하위 항목까지 기본으로 펼쳐진다. 같은 줄이나 노드를 다시 그릴 때는 직접 접은 부분과 스크롤 위치만 유지한다. 선택지는 모든 한국어 문구를 먼저 보여 준 뒤 문구별 연결·조건을 표시한다. 주문은 술과 손님, 대사는 문구·표정부터 수정한다. 미리보기 설정과 원본 ID는 아래에 있다. 주문의 술은 이름으로 고르고, 대사/선택지 조건은 조건 조합으로 작성할 수 있다. 검색한 상태에서 순서 이동을 막아 보이지 않는 줄과 자리가 바뀌지 않도록 한다.

한국어 대사·선택지의 **텍스트 색상** 버튼은 추천 팔레트, 운영체제 색상판, HEX/RGB 직접 입력과 실시간 바 화면 미리보기를 제공한다. 드래그한 글자만 적용하며 선택이 없으면 전체 대사에 적용한다. 기존 `<color=#RRGGBB>...</color>` 안에 커서를 놓으면 해당 구간의 색상을 수정한다. 적용 시 색상 태그를 CSV 텍스트에 기록하고 Ctrl/Cmd+Z 한 번으로 되돌린다. 취소/Esc는 미리보기만 원복하고 편집 이력·CSV·임시 저장을 바꾸지 않는다. 색상판의 미확정 값은 저장하지 않는다.

대사·선택지·조건 입력 중에도 `Ctrl+Z`(Mac: `Cmd+Z`)로 되돌린다. 다시 실행은 `Ctrl+Shift+Z` / `Cmd+Shift+Z` 또는 `Ctrl+Y`다. 0.8초 이내의 연속 입력은 묶고, 붙여넣기·입력 종류 변경·필드 이동은 별도 변경으로 기록한다. 되돌린 뒤에도 입력칸 초점을 유지하며 미리보기와 임시 편집을 함께 갱신한다. 검색·미리보기 전용 조건 입력은 CSV 편집 이력과 분리한다. 실제 CSV 저장 시 편집 이력은 초기화된다.

## 로컬 저장과 GitHub 내보내기

- **로컬:** 저장소 루트에서 `python3 serve.py [포트]`를 실행한다. 기존 서버가 켜져 있으면 재시작해야 새 저장 API가 생긴다. Python 3와 Node가 필요하다. PATH의 Node, 없으면 Codex 번들 Node를 사용한다. 편집기 상단이 `로컬 · 실제 CSV 저장`인지 확인한다.
- 저장은 `story/steps.csv`, `bar_choices.csv`, `bar_choice_groups.csv`, `web-views.json` 중 바뀐 파일에 적용한다. 새 일차를 만든 경우에만 `settings/days.csv`, `story/scenes.csv`, `story/script_files.csv`, `system/data_sets.csv`, `system/row_formats.csv`에 기존 형식의 행을 덧붙인다. `game-data.js`, `campaign-data.js`도 동일 원본으로 재생성한다. 기존 사용자 수정은 현재 파일을 기준으로 읽으며, 불러온 뒤 다른 프로그램에서 원본을 바꾸면 덮어쓰지 않고 충돌을 알린다.
- 변경 전 CSV/연결/런타임은 `artifacts/dialogue-editor-backups/<시각-고유값>/`에 보관한다. 복구 시 해당 폴더의 `shared-csv/`와 `runtime/` 파일을 각각 `bar-playtest/data/`의 같은 위치에 되돌린다. 테스트용 백업이 아니라 사용자 저장마다 생성하는 복구본이며 Git에는 포함하지 않는다.
- **GitHub Pages / 정적 서버:** 실제 서버 파일 쓰기가 불가능하므로 `CSV ZIP 내보내기`로 제공한다. 변경 CSV, 필요한 웹 연결 파일, 재생성된 런타임 2개가 저장소 상대 경로로 담긴다. ZIP 안의 `bar-playtest/`를 같은 버전 저장소에 병합한 뒤 커밋/푸시해야 웹에 반영된다. 내보냈다고 GitHub에 저장됐다고 표시하지 않는다.
- 로컬에서 저장 API를 제공하지 않는 옛 서버는 상단에 연결 오류를 표시한다. 같은 포트로 `serve.py`를 다시 실행하고 **저장 연결 다시 확인**을 누르면 미저장 편집을 유지한 채 재연결한다. 로컬의 기본 버튼은 항상 실제 CSV 저장이며, 연결 실패를 ZIP 내보내기로 바꾸지 않는다. 별도의 **ZIP 파일만 내보내기**는 다운로드만 한다.
- 실제 저장 직전 서버 연결·토큰·원본 revision을 다시 확인한다. 서버 재시작은 편집 내용을 지우지 않으며, 외부에서 CSV가 바뀌면 저장을 차단하고 ZIP 보관/원본 재불러오기를 안내한다. 서버와 브라우저 주소의 포트가 같아야 하며, 다른 포트의 임시 저장은 자동 이전되지 않는다.
- 정적 CSV를 읽을 때도 UTF-8 BOM을 보존해 서버와 같은 원본 revision을 계산한다. 예전 BOM 제거 방식의 임시 편집은 현재 원본을 같은 방식으로 계산했을 때 일치하는 경우에만 복원을 허용한다.
- 브라우저 임시 보관은 저장과 다르다. 같은 원본 버전에서만 복원 여부를 묻고, 원본이 바뀌면 자동 병합하지 않는다. 원본 다시 불러오기는 확인 후 임시 편집을 버린다.
- Unity/Notion/Drive와 자동 동기화하지 않는다. 엔진에 반영할 때는 공통 CSV 변경을 별도 검토한다.

### 저장 후 본편·일차 테스트 자동 반영

- 같은 로컬 주소/포트로 열린 게임은 실제 저장 성공 시 변경 신호를 받고 서버에서 최신 대본을 다시 읽는다. 새로고침 없이 다음 장면, 새 본편 시작, 일차 테스트 재시작에 반영한다. 이미 열려 있던 구버전 페이지는 이 기능이 포함되도록 처음 한 번 새로고침한다.
- **진행 중인 장면은 끝까지 기존 대본을 유지한다.** 대사 추가·삭제나 선택지 변경으로 진행 인덱스가 어긋나고 주문·코스터·보상이 중복 실행되는 것을 막는다. 현재 장면 수정본을 즉시 시험하려면 해당 일차 테스트를 다시 시작한다. 돈·플래그·좌석·제조·대화 기록은 자동 반영이 초기화하지 않는다.
- `live-data.js`는 저장 알림/탭 복귀 시 `/api/dialogue-editor/runtime`를 읽고 바 변경본을 대기시킨다. `Game.reset`, `startStoryPhase`, `loadScene`에서 세 대본 표와 바 본편 투영을 함께 교체한다. 캠페인 종료 시 복구할 표도 최신화하여 이전 대본으로 되돌아가지 않는다. 외부·테라스·회상은 위 외부 저장 계약으로 갱신하며 레시피·일반 손님 데이터는 대상이 아니다.
- 미저장 편집·ZIP 내보내기는 신호를 보내지 않는다. 미리보기 iframe에는 자동 갱신을 설치하지 않는다. 로딩 실패 시 기존 대본/진행을 유지하며 다음 탭 복귀에서 다시 시도한다. GitHub에서는 로컬 갱신 요청을 보내지 않는다.

## 전체 일차 플래그와 저장 전 검수

플로우 차트와 대사 편집기의 **플래그 조건 선택**은 플래그 관리와 같은 전체 일차 목록을 사용한다. 이름·ID·사용 일차로 찾은 뒤 **참 / 거짓**을 누른다. 다른 플래그나 호감도·등급 조건은 그대로 두고 같은 플래그의 값만 바꾼다. 선택지의 **플래그 값 설정**은 해당 선택지를 골랐을 때 기록할 값이다. 선택지 편집에는 즉시 반영되며, 노드 조건과 분기 핀은 기존처럼 적용하거나 연결해야 한다. 자동 연결용 플래그는 선택기에 나오지 않는다.

목록에 없는 영문 ID는 검색 결과의 **새 플래그 만들기 → 참 / 거짓**으로 바로 쓴다. 대본의 조건에서 만들면 값을 확인하는 식만 추가되며, 선택지의 값 기록에서 만들면 그때만 값을 쓴다. 적용 전에 취소하면 빈 플래그가 남지 않는다. 플래그 칩을 다시 누르면 값 변경·다른 플래그로 교체·이 위치에서만 제거할 수 있다. 미연결 핀에서만 쓰는 이름은 편집기 목록에는 보이지만 연결 전에는 CSV에 포함하지 않는다.

색상·아이콘은 **플래그 관리 → 해당 플래그 → 색상 / 아이콘**에서 바꾼다. 노드와 선택지 핀, 편집기, 검색 목록에 같은 표시가 쓰인다. 표시는 브라우저에만 저장되며 CSV 저장·내보내기, 엔진, 게임 세이브와 무관하다.

왼쪽 **플래그 관리**는 현재 편집 중인 모든 바 일차를 읽는다. 이름을 검색하거나 일차를 고르면 조건에서 읽는 곳과 값을 기록하는 곳이 표시된다. 사용 위치를 누르면 해당 대사나 선택지로 이동한다. **플래그 추가**에서 장면·줄·선택지와 처음 기록할 값을 정한다. 새 데이터 타입은 없다. 해당 위치에서 실행되는 기존 `effects`에만 대입을 추가한다.

이름 변경은 자유 대사 안의 글자가 아니라 모든 일차의 `when`·`effects`에 있는 정확한 플래그 이름만 바꾼다. 삭제는 조건과 값 기록까지 제거하므로 확인이 필요하다. 빈 조건은 항상 실행된다는 뜻이다. 복합 비교나 연결된 분기에서 의미가 달라지면 직접 먼저 수정한다. 게임이 직접 읽는 이름, 다른 CSV와 공유하는 이름, 자동 분기 연결용 이름은 보호한다. 변경은 되돌릴 수 있으며 CSV 저장 전에는 본편에 반영되지 않는다.

**검수 콘솔**은 저장하지 않고도 열 수 있다. 태그 오류, 선택 불가능한 메뉴, 잘못된 장면 이동, 입장하지 않은 손님의 코스터·주문, 제조/제공 연결 오류 등을 위치와 함께 보여준다. 자동 입장한 손님도 원본의 `entrance=seated`를 사용한다. 오류는 로컬 저장과 ZIP 내보내기를 막는다. 도달할 수 없는 줄, 쓰는 곳이 없는 플래그, 브라우저에만 있는 미연결 핀은 주의로 구분한다. 순서대로 다음 줄로 넘어가는 기본 연결은 오류가 아니다. 검사할 경로 수가 한도를 넘으면 미검사 경고를 내므로 실제 플레이 검수를 대체하지 않는다.

- `flag-tools.js`: 플래그 사용 위치와 일괄 수정. `workbench.js` / `workbench.css`: 관리 팝업, 검수 결과, 해당 위치 이동.
- `bar-audit.js`: 선택지·효과 태그, 선택 결과와 좌석/주문 상태에 따른 경로 검수. 구조/문법 검사와 함께 편집기·저장 서버에서 같은 기준을 사용한다.
- `draft-store.js`: 탭마다 임시본을 분리한다. 다른 탭에서 복원을 거절해도 기존 임시본은 지우지 않는다. 서버 응답 대기 중에는 저장 창을 닫을 수 없고, 보낸 시점의 내용만 저장 완료로 처리한다.

## 소유 파일과 보호 장치

- `src/dev/dialogue-editor/editor-model.js`: CSV 원본 스냅샷·행 ID·순서·Undo/Redo·변경 비교·검증. 새 줄은 기존 엔진 행 형식을 사용한다. 선택지 줄 복제 시 그룹과 선택지 ID도 별도로 생성하므로 원본 선택지가 같이 바뀌지 않는다. 개점 장면의 투영 제외 초기 배치 줄은 삭제/이동을 막는다.
- `editor.js`, `editor.css`: 편집 입력·목록·변경 확인·로컬/웹 구분. 우측 입력 중 전체 화면을 다시 생성하지 않는다.
- `color-picker.js`: 선택 구간 색상 편집·팔레트 입력 검증. 적용 전 색상은 미리보기 메시지에만 전달하며 CSV 모델과 분리한다.
- `preview-bridge.js`: 독립 iframe의 기존 `Game`과 바 화면을 사용한다. 프리뷰 전용 clock이 본편 pump/진행/보상 실행을 막고, 메시지는 같은 출처의 부모 창만 받는다. 입장·퇴장·표정·코스터·빈잔의 상태를 재구성한다. 업데이트 팝업과 본편 입력은 프리뷰에서 열지 않는다.
- `src/shared/dialogue/text-effects.js`: 본편 바와 편집기 공통의 안전한 태그 처리. HTML을 그대로 삽입하지 않는다. CSV 색상/크기/속도 별칭, `shake`, `wave`, `pop`, `color=#RRGGBB`, `size=130%`, `b/i/u`, `br`, 숫자 밀리초 대기 태그를 해석한다. 엔진의 임의 `fx=` 프리셋·TMP sprite 등 미지원 태그는 편집 저장 시 오류를 표시한다. 효과 모션은 웹 CSS 구현이며 Unity 메시 애니메이션의 픽셀 단위 동일성을 보장하지 않는다.
- `src/shared/data/runtime-projection.js`: 기존 빌더와 편집기가 공유하는 원본 → 실행 데이터 투영. `tools/lib/shared-data-views.cjs`는 기존 호출 경로 호환용이다.
- `serve.py`, `tools/dialogue-editor-storage.cjs`: loopback 전용, Host/Origin/임시 토큰/요청 크기 검사, 저장 직렬화, 허용 파일 목록, 원본 revision 충돌 검사, CSV 검증, 백업과 파일 교체. 도중 실패하면 이미 교체한 파일을 복구한다. OS 강제 종료 등 다중 파일 교체 도중 프로세스가 끊긴 경우 백업으로 복구한다.
- 저장 헬퍼의 stdin은 UTF-8 스트림 디코더를 사용한다. 큰 CSV의 청크 경계에서 한글이 잘리지 않도록 하며, 테스트는 한글 한 글자의 중간에서 입력을 분리해 실제 자식 프로세스로 전송한다.
- `export-package.js`: 동일한 원본과 투영 결과로 CSV/런타임 ZIP 생성. 브라우저에서 다운로드만 수행한다.

검증: `test-dialogue-editor.cjs`는 별도 임시 복사본에서 CSV·런타임 실제 저장/백업/충돌 차단을 검사한다. `test-dialogue-editor-ui.cjs`는 `EDITOR_URL`(기본 `http://127.0.0.1:8124`)의 새 로컬 서버에서 2인 화면·효과·실시간 수정·선택지·Undo·내보내기를 검사한다. 운영 CSV에는 테스트 데이터를 쓰지 않는다.
