# 대사 편집기

시뮬레이터의 **대사 편집** 탭(`/bar-playtest/dialogue-editors.html`)에서 바 내부와 외부를 선택한다. 기존 `/bar-playtest/dialogue-editor.html`은 0~3일차 바 장면 7개, `/bar-playtest/outside-dialogue-editor.html`은 CSV의 외부·테라스·회상·도입 80개 원본 흐름을 대화 단위 73개로 묶어 표시한다. 선택지 복사본·공통 후속 대사는 원래 흐름 안에서 확인하며 신규 분기를 만들면 항목이 늘어난다. 미리보기는 본편 진행 상태를 변경하지 않는다.

## 외부 편집기 · 현재 지원 범위

- 왼쪽은 NPC/장소별 흐름과 전체 본문 검색·즐겨찾기, 가운데는 검정 격자 배경의 캐릭터/말풍선 미리보기와 줄 목록, 오른쪽은 선택 행 편집이다. 흐름 간 이동 기록과 관련 흐름 바로가기, 현재 줄/연속 재생, 추가·복제·삭제·순서 이동, Ctrl/Cmd+Z/Shift+Z, 변경 비교, 버전 일치 임시 편집 복원을 제공한다.
- **기존 CSV 스키마를 확장하지 않았다.** `web-views.json`의 outside, campaign.scenes, prologue를 실제 부모·분기 ID로 역추적한다. 바의 복사본이나 웹 미사용 엔진 예시 대본을 본편 외부 대사로 표시하지 않는다. 빈 연결 장면은 목록에서 제외한다.
- `story/steps.csv`의 실제 투영 텍스트와 지원되는 화자를 저장한다. 일반 say는 같은 템플릿으로 추가/복제한다. 하위 강조 데이터·보상·기존 연출 행은 삭제/복제를 막는다. 신규 선택지 장면은 추가/삭제할 수 있으며, 삭제 시 편집기가 만든 자식 분기도 함께 정리한다.
- 선택지는 대사 목록의 해당 시점에 포함한다. 신문 NPC의 `options` 복사본, 정보 주제·상점 물품 메뉴는 왼쪽 독립 항목으로 표시하지 않는다. 신문 정답/오답 뒤 공통 합류·마무리, 신도 인사 뒤 마무리, 상점 퀴즈 설명도 이어지는 목록에서 본다. 실제로 갈라지는 분기는 별도 흐름이다.
- 본편과 같은 `LunaWorldChoices`/`world-choices.css`로 선택바·모서리·E 표시·500ms 입력 보호·불가 사유·빨간색/글리칭을 재현한다. 빈 선택지 행은 직전 대사를 유지하며 직전 대사도 없으면 말풍선을 숨긴다. 휠/키 조작은 미리보기 영역에 한정하여 편집 입력을 가로채지 않는다.
- 같은 선택지 장면에서 문구·조건·소지금만 바뀌면 기존 버튼 요소를 유지하고 내용만 갱신한다. 입력할 때마다 등장 애니메이션을 재생하거나 선택/입력 유예 시간을 초기화하지 않는다. 다른 장면으로 이동하거나 메뉴를 닫았다 다시 열면 정상적으로 등장한다.
- 불량배·정보 구매·개시바·신문 NPC·노숙자·부비·수리공·갱단·옷장의 연결 메뉴는 **1~4개 선택지 추가/삭제/순서·문구·추가 조건·불가 사유**를 저장한다. 후속 연결은 `continue`(현재 흐름 계속), `end`(대화 종료), `native:<기존 동작 ID>`, `flow:<외부 흐름 ID>`다. 새 대사 분기는 기존 `result_steps` 구조로 만들며 일반 분기는 읽은 뒤 원래 다음 줄로 합류한다. 신문 NPC의 커스텀 분기는 기존 공통 대사·기어 지급·완료 플래그 경로로 합류한다.
- 기존 동작의 가격·재고·아이템 소유·완료 검사와 보상 실행은 해당 NPC가 소유한다. 편집 조건은 여기에 AND로 추가된다. 이미 판매한 상품 등 원래 숨겨지는 동작은 별칭 선택지를 만들어도 노출하지 않는다. 삭제된 선택지 ID를 직접 호출해도 실행을 거부한다. 기존 선택지를 다른 대사 분기로 연결하면 그 선택지의 원래 구매/수리 동작 대신 지정한 대화를 실행한다.
- **미리보기 전용:** 줄별/인물별 캐릭터 시트·방향·재생 속도·보유 행동 클립, 소지금/플래그, 재료·기어·엠블럼·목표·돈 알림. 이 설정은 CSV·임시 대사 파일에 들어가지 않는다. 동일 NPC도 줄마다 다른 시트를 시험할 수 있지만 본편 변경 기능으로 오인하지 않도록 표시한다. 실제 원본 NPC Idle, 루나 Idle/Walk/Run, 삼호 Idle, 개시바 시트를 사용한다. 외부 시트가 등록되지 않은 인물은 이름과 자리표시자로 표시하며 다른 인물로 몰래 대체하지 않는다. 말풍선 스킨·마침표 타이핑은 본편 공통 모듈을 사용한다. 보상 미리보기는 진행/인벤토리를 변경하지 않는다.
- **지원 대기:** 동적 짧은 응답, 엘리베이터 메뉴, CSV 밖 TV 다큐 문구, 신규 아이템/보상 명령, 텍스트 효과 태그, 임의 타임라인/애니메이션 본편 저장. 자동 배경 대화와 캠페인 컷씬에는 플레이어 입력을 기다리는 신규 메뉴를 삽입하지 않는다. NPC별 애니메이션 실행 계약도 별도다. 도움말과 해당 항목에 제한을 표시한다.
- 외부 텍스트에는 `<shake>` 등의 효과 태그를 저장하지 않는다. 묶인 말줄임표는 `...`로 정규화한다. 영문 자동 번역은 하지 않는다.
- `characters/field_animations.csv`의 FieldAnimations는 캐릭터·동작·리소스 목록이다. 그 목록의 존재와 외부 대사 줄에서 특정 인물의 클립·유지 범위를 실행하는 기능은 별개다. 현재 편집기는 기존 `arg`의 의미를 임의로 바꾸거나 새 명령을 저장하지 않는다. 애니메이션 본편 적용은 이 실행 계약을 정한 후 연결해야 한다.

### 외부 저장·자동 반영

외부 저장은 같은 loopback API에 `mode: outside`로 전달한다. 허용 파일은 `story/steps.csv`, `story/street_choices.csv`, `web-views.json`뿐이다. CSV 열/스키마 파일은 추가하지 않는다. 옵션 소유 행은 필요할 때 기존 `steps_format_62`, 신규 옵션은 `street_choices_format_02`, 신규 분기 대사는 `steps_format_30`을 사용한다. 기존 화자 이름은 웹 연결 설정에 보존한다.

`web-views.json.outsideChoiceEdits`는 선택지 부모 행 ID별 `stepId/who/active/routes`를 기록한다. **문구·조건은 CSV, 활성 순서·본편 코드 동작 연결은 이 설정**이 정본이다. 삭제한 기존 옵션의 원본/하위 대사는 다른 연결을 깨지 않도록 보관하고 `active`에서 제거한다. 신규 선택지 장면 자체의 삭제는 편집기 생성 하위 트리까지 제거한다. 새 분기의 `outside.editor/...` 참조도 함께 저장한다. 이 웹 실행 어댑터는 Unity에서 자동 실행되지 않으므로 엔진 연동 시 별도 구현이 필요하다.

서버는 범위 밖 데이터, 잘못된 부모·후속 연결, 빈/5개 이상 메뉴를 거부한다. CSV 검증·revision 충돌 검사·백업 후 실행 데이터도 함께 재생성한다. GitHub는 같은 구조의 ZIP을 내보내며 엔진·Notion·Drive는 변경하지 않는다.

`/api/dialogue-editor/runtime`의 `exterior`에 sharedStory/선택지/scenes/prologue를 담는다. live-data는 기존 NPC 모듈이 캡처한 배열의 정체성을 유지하며 내용을 갱신한다. 갱신 전에 이미 재생 중인 외부/배경/캠페인 대사의 행 배열을 분리해 현재 흐름을 보존한다. **새로 시작하는 대화 흐름/회상부터** 수정본을 사용하고, 돈·플래그·보상·완료 상태는 재실행하지 않는다. 한 상호작용 안에서도 선택 후 별도 흐름을 시작하면 그 흐름은 최신본이다. 바는 기존대로 장면 경계에서 적용한다.

소유: `outside-model.js`(CSV 범위/역참조/검증), `outside-editor.js`/CSS(편집 UI), `outside-preview.js`(독립 검수 화면), `storage-client.js`(저장 통신), `features/outside/events/outside-authoring.js`(본편 선택지 연결). 테스트 `test-outside-dialogue-editor.cjs`와 `test-outside-dialogue-editor-ui.cjs`는 별도 임시 복사본에 실제 저장하며 운영 CSV에는 검사 문장을 쓰지 않는다.

## 사용

1. 일차와 개점 전/단골 영업 장면을 고른다. 왼쪽 목록의 줄을 누르면 그 앞의 입장·퇴장·표정·코스터·잔 상태를 복원하고 실제 바 렌더러로 표시한다.
2. 오른쪽에서 한국어/영문, 화자, 표정, 인수, 실행 조건, 효과를 편집한다. 대사·표정·최대 4개 선택지는 즉시 미리보기에 반영된다. 추가/복제/삭제/위아래 이동, 검색, 되돌리기/다시 실행을 제공한다. 입장 좌석 수에 따라 1인/2인 카메라 구도가 실제 바와 같이 바뀐다.
3. 현재 줄 재생은 타이핑·입 움직임을 확인한다. 연속 재생은 선택지에서 멈추며, 화면의 선택지를 눌러 진행한다. 제조/코스터/튜토리얼의 실제 조작은 생략한 **편집용 재생**이다. 제조 성공을 전제로 잔 상태를 표시하며 전체 게임 플레이 테스트를 대체하지 않는다. 미리보기 조건의 돈·플래그는 CSV에 저장되지 않는다.
4. 변경 내역에서 추가·삭제·필드 값 차이를 확인하고 확정한다. 태그·CSV 구조·선택지 연결 오류가 있으면 저장/내보내기를 막는다. 원래 조건문으로 실행되지 않는 줄도 직접 선택하면 검토할 수 있으며 경고가 표시된다.

## 색상과 편집 단축키

한국어 대사·선택지의 **텍스트 색상** 버튼은 추천 팔레트, 운영체제 색상판, HEX/RGB 직접 입력과 실시간 바 화면 미리보기를 제공한다. 드래그한 글자만 적용하며 선택이 없으면 전체 대사에 적용한다. 기존 `<color=#RRGGBB>...</color>` 안에 커서를 놓으면 해당 구간의 색상을 수정한다. 적용 시 색상 태그를 CSV 텍스트에 기록하고 Ctrl/Cmd+Z 한 번으로 되돌린다. 취소/Esc는 미리보기만 원복하고 편집 이력·CSV·임시 저장을 바꾸지 않는다. 색상판의 미확정 값은 저장하지 않는다.

대사·선택지·조건 입력 중에도 `Ctrl+Z`(Mac: `Cmd+Z`)로 되돌린다. 다시 실행은 `Ctrl+Shift+Z` / `Cmd+Shift+Z` 또는 `Ctrl+Y`다. 0.8초 이내의 연속 입력은 묶고, 붙여넣기·입력 종류 변경·필드 이동은 별도 변경으로 기록한다. 되돌린 뒤에도 입력칸 초점을 유지하며 미리보기와 임시 편집을 함께 갱신한다. 검색·미리보기 전용 조건 입력은 CSV 편집 이력과 분리한다. 실제 CSV 저장 시 편집 이력은 초기화된다.

## 로컬 저장과 GitHub 내보내기

- **로컬:** 저장소 루트에서 `python3 serve.py [포트]`를 실행한다. 기존 서버가 켜져 있으면 재시작해야 새 저장 API가 생긴다. Python 3와 Node가 필요하다. PATH의 Node, 없으면 Codex 번들 Node를 사용한다. 편집기 상단이 `로컬 · 실제 CSV 저장`인지 확인한다.
- 저장은 `story/steps.csv`, `bar_choices.csv`, `bar_choice_groups.csv`, `web-views.json` 중 바뀐 파일에만 적용한다. `game-data.js`, `campaign-data.js`도 동일 원본으로 재생성한다. 기존 사용자 수정은 현재 파일을 기준으로 읽으며, 불러온 뒤 다른 프로그램에서 원본을 바꾸면 덮어쓰지 않고 충돌을 알린다.
- 변경 전 CSV/연결/런타임은 `artifacts/dialogue-editor-backups/<시각-고유값>/`에 보관한다. 복구 시 해당 폴더의 `shared-csv/`와 `runtime/` 파일을 각각 `bar-playtest/data/`의 같은 위치에 되돌린다. 테스트용 백업이 아니라 사용자 저장마다 생성하는 복구본이며 Git에는 포함하지 않는다.
- **GitHub Pages / 정적 서버:** 실제 서버 파일 쓰기가 불가능하므로 `CSV ZIP 내보내기`로 제공한다. 변경 CSV, 필요한 웹 연결 파일, 재생성된 런타임 2개가 저장소 상대 경로로 담긴다. ZIP 안의 `bar-playtest/`를 같은 버전 저장소에 병합한 뒤 커밋/푸시해야 웹에 반영된다. 내보냈다고 GitHub에 저장됐다고 표시하지 않는다.
- 로컬에서 저장 API를 제공하지 않는 옛 서버는 상단에 연결 오류를 표시한다. 같은 포트로 `serve.py`를 다시 실행하고 **저장 연결 다시 확인**을 누르면 미저장 편집을 유지한 채 재연결한다. 로컬의 기본 버튼은 항상 실제 CSV 저장이며, 연결 실패를 ZIP 내보내기로 바꾸지 않는다. 별도의 **ZIP 파일만 내보내기**는 다운로드만 한다.
- 실제 저장 직전 서버 연결·토큰·원본 revision을 다시 확인한다. 서버 재시작은 편집 내용을 지우지 않으며, 외부에서 CSV가 바뀌면 저장을 차단하고 ZIP 보관/원본 재불러오기를 안내한다. 서버와 브라우저 주소의 포트가 같아야 하며, 다른 포트의 임시 저장은 자동 이전되지 않는다.
- 정적 CSV를 읽을 때도 UTF-8 BOM을 보존해 서버와 같은 원본 revision을 계산한다. 예전 BOM 제거 방식의 임시 편집은 현재 원본을 같은 방식으로 계산했을 때 일치하는 경우에만 복원을 허용한다.
- 브라우저 임시 보관은 저장과 다르다. 같은 원본 버전에서만 복원 여부를 묻고, 원본이 바뀌면 자동 병합하지 않는다. 원본 다시 불러오기는 확인 후 임시 편집을 버린다.
- Unity/Notion/Drive와 자동 동기화하지 않는다. 엔진에 반영할 때는 공통 CSV 변경을 별도 검토한다.

### 저장 후 본편·일차 테스트 자동 반영

- 같은 로컬 주소/포트로 열린 게임은 실제 저장 성공 시 변경 신호를 받고 서버에서 최신 대본을 다시 읽는다. 새로고침 없이 다음 장면, 새 본편 시작, 일차 테스트 재시작에 반영한다. 이미 열려 있던 구버전 페이지는 이 기능이 포함되도록 처음 한 번 새로고침한다.
- **진행 중인 장면은 끝까지 기존 대본을 유지한다.** 대사 추가·삭제나 선택지 변경으로 진행 인덱스가 어긋나고 주문·코스터·보상이 중복 실행되는 것을 막는다. 현재 장면 수정본을 즉시 시험하려면 해당 일차 테스트를 다시 시작한다. 돈·플래그·좌석·제조·대화 기록은 자동 반영이 초기화하지 않는다.
- `live-data.js`는 저장 알림/탭 복귀 시 `/api/dialogue-editor/runtime`를 읽고 바 변경본을 대기시킨다. `Game.reset`, `startStoryPhase`, `loadScene`에서 세 대본 표와 바 본편 투영을 함께 교체한다. 캠페인 종료 시 복구할 표도 최신화하여 이전 대본으로 되돌아가지 않는다. 외부·테라스·회상은 위 외부 저장 계약으로 갱신하며 레시피·일반 손님 데이터는 대상이 아니다.
- 미저장 편집·ZIP 내보내기는 신호를 보내지 않는다. 미리보기 iframe에는 자동 갱신을 설치하지 않는다. 로딩 실패 시 기존 대본/진행을 유지하며 다음 탭 복귀에서 다시 시도한다. GitHub에서는 로컬 갱신 요청을 보내지 않는다.

## 소유 파일과 보호 장치

- `src/dev/dialogue-editor/editor-model.js`: CSV 원본 스냅샷·행 ID·순서·Undo/Redo·변경 비교·검증. 새 줄은 기존 엔진 행 형식을 사용한다. 선택지 줄 복제 시 그룹과 선택지 ID도 별도로 생성하므로 원본 선택지가 같이 바뀌지 않는다. 개점 장면의 투영 제외 초기 배치 줄은 삭제/이동을 막는다.
- `editor.js`, `editor.css`: 편집 입력·목록·변경 확인·로컬/웹 구분. 우측 입력 중 전체 화면을 다시 생성하지 않는다.
- `color-picker.js`: 선택 구간 색상 편집·팔레트 입력 검증. 적용 전 색상은 미리보기 메시지에만 전달하며 CSV 모델과 분리한다.
- `preview-bridge.js`: 독립 iframe의 기존 `Game`과 바 화면을 사용한다. 프리뷰 전용 clock이 본편 pump/진행/보상 실행을 막고, 메시지는 같은 출처의 부모 창만 받는다. 입장·퇴장·표정·코스터·빈잔의 상태를 재구성한다. 업데이트 팝업과 본편 입력은 프리뷰에서 열지 않는다.
- `src/shared/dialogue/text-effects.js`: 본편 바와 편집기 공통의 안전한 태그 처리. HTML을 그대로 삽입하지 않는다. CSV 색상/크기/속도 별칭, `shake`, `wave`, `pop`, `color=#RRGGBB`, `size=130%`, `b/i/u`, `br`, 숫자 밀리초 대기 태그를 해석한다. 엔진의 임의 `fx=` 프리셋·TMP sprite 등 미지원 태그는 편집 저장 시 오류를 표시한다. 효과 모션은 웹 CSS 구현이며 Unity 메시 애니메이션의 픽셀 단위 동일성을 보장하지 않는다.
- `src/shared/data/runtime-projection.js`: 기존 빌더와 편집기가 공유하는 원본 → 실행 데이터 투영. `tools/lib/shared-data-views.cjs`는 기존 호출 경로 호환용이다.
- `serve.py`, `tools/dialogue-editor-storage.cjs`: loopback 전용, Host/Origin/임시 토큰/요청 크기 검사, 저장 직렬화, 허용 파일 목록, 원본 revision 충돌 검사, CSV 검증, 백업과 파일 교체. 도중 실패하면 이미 교체한 파일을 복구한다. OS 강제 종료 등 다중 파일 교체 도중 프로세스가 끊긴 경우 백업으로 복구한다.
- 저장 헬퍼의 stdin은 UTF-8 스트림 디코더를 사용한다. 큰 CSV의 청크 경계에서 한글이 잘리지 않도록 하며, 테스트는 한글 한 글자의 중간에서 입력을 분리해 실제 자식 프로세스로 전송한다.
- `export-package.js`: 동일한 원본과 투영 결과로 CSV/런타임 ZIP 생성. 브라우저에서 다운로드만 수행한다.

검증: `test-dialogue-editor.cjs`는 별도 임시 복사본에서 CSV·런타임 실제 저장/백업/충돌 차단을 검사한다. `test-dialogue-editor-ui.cjs`는 `EDITOR_URL`(기본 `http://127.0.0.1:8124`)의 새 로컬 서버에서 2인 화면·효과·실시간 수정·선택지·Undo·내보내기를 검사한다. 운영 CSV에는 테스트 데이터를 쓰지 않는다.
