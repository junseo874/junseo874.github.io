# 바 대사 편집기

시뮬레이터의 **대사 편집** 탭(`/bar-playtest/dialogue-editor.html`)은 현재 본편 0~3일차의 바 장면 7개를 편집한다. 외부·테라스·컷씬 편집기는 아니다. 본편 저장/진행 상태는 변경하지 않는다.

## 사용

1. 일차와 개점 전/단골 영업 장면을 고른다. 왼쪽 목록의 줄을 누르면 그 앞의 입장·퇴장·표정·코스터·잔 상태를 복원하고 실제 바 렌더러로 표시한다.
2. 오른쪽에서 한국어/영문, 화자, 표정, 인수, 실행 조건, 효과를 편집한다. 대사·표정·최대 4개 선택지는 즉시 미리보기에 반영된다. 추가/복제/삭제/위아래 이동, 검색, 되돌리기/다시 실행을 제공한다. 입장 좌석 수에 따라 1인/2인 카메라 구도가 실제 바와 같이 바뀐다.
3. 현재 줄 재생은 타이핑·입 움직임을 확인한다. 연속 재생은 선택지에서 멈추며, 화면의 선택지를 눌러 진행한다. 제조/코스터/튜토리얼의 실제 조작은 생략한 **편집용 재생**이다. 제조 성공을 전제로 잔 상태를 표시하며 전체 게임 플레이 테스트를 대체하지 않는다. 미리보기 조건의 돈·플래그는 CSV에 저장되지 않는다.
4. 변경 내역에서 추가·삭제·필드 값 차이를 확인하고 확정한다. 태그·CSV 구조·선택지 연결 오류가 있으면 저장/내보내기를 막는다. 원래 조건문으로 실행되지 않는 줄도 직접 선택하면 검토할 수 있으며 경고가 표시된다.

## 색상과 편집 단축키

한국어 대사·선택지의 **텍스트 색상** 버튼은 추천 팔레트, 운영체제 색상판, HEX/RGB 직접 입력과 실시간 바 화면 미리보기를 제공한다. 드래그한 글자만 적용하며 선택이 없으면 전체 대사에 적용한다. 기존 `<color=#RRGGBB>...</color>` 안에 커서를 놓으면 해당 구간의 색상을 수정한다. 적용 시 색상 태그를 CSV 텍스트에 기록하고 Ctrl/Cmd+Z 한 번으로 되돌린다. 취소/Esc는 미리보기만 원복하고 편집 이력·CSV·임시 저장을 바꾸지 않는다. 색상판의 미확정 값은 저장하지 않는다.

대사·선택지·조건 입력 중에도 `Ctrl+Z`(Mac: `Cmd+Z`)로 되돌린다. 다시 실행은 `Ctrl+Shift+Z` / `Cmd+Shift+Z` 또는 `Ctrl+Y`다. 0.8초 이내의 연속 입력은 묶고, 붙여넣기·입력 종류 변경·필드 이동은 별도 변경으로 기록한다. 되돌린 뒤에도 입력칸 초점을 유지하며 미리보기와 임시 편집을 함께 갱신한다. 검색·미리보기 전용 조건 입력은 CSV 편집 이력과 분리한다. 실제 CSV 저장 시 편집 이력은 초기화된다.

## 로컬 저장과 GitHub 내보내기

- **로컬:** 저장소 루트에서 `python3 serve.py [포트]`를 실행한다. 기존 서버가 켜져 있으면 재시작해야 새 저장 API가 생긴다. Python 3와 Node가 필요하다. PATH의 Node, 없으면 Codex 번들 Node를 사용한다. 편집기 상단이 `로컬 · 실제 CSV 저장`인지 확인한다.
- 저장은 `story/steps.csv`, `bar_choices.csv`, `bar_choice_groups.csv`, `web-views.json` 중 바뀐 파일에만 적용한다. `game-data.js`, `campaign-data.js`도 동일 원본으로 재생성한다. 기존 사용자 수정은 현재 파일을 기준으로 읽으며, 불러온 뒤 다른 프로그램에서 원본을 바꾸면 덮어쓰지 않고 충돌을 알린다.
- 변경 전 CSV/연결/런타임은 `artifacts/dialogue-editor-backups/<시각-고유값>/`에 보관한다. 복구 시 해당 폴더의 `shared-csv/`와 `runtime/` 파일을 각각 `bar-playtest/data/`의 같은 위치에 되돌린다. 테스트용 백업이 아니라 사용자 저장마다 생성하는 복구본이며 Git에는 포함하지 않는다.
- **GitHub Pages / 정적 서버:** 실제 서버 파일 쓰기가 불가능하므로 `CSV ZIP 내보내기`로 제공한다. 변경 CSV, 필요한 웹 연결 파일, 재생성된 런타임 2개가 저장소 상대 경로로 담긴다. ZIP 안의 `bar-playtest/`를 같은 버전 저장소에 병합한 뒤 커밋/푸시해야 웹에 반영된다. 내보냈다고 GitHub에 저장됐다고 표시하지 않는다.
- 로컬에서 저장 API를 제공하지 않는 옛 정적 서버는 내보내기만 가능하다. 자동으로 원본 파일 쓰기에 성공한 것처럼 취급하지 않는다.
- 브라우저 임시 보관은 저장과 다르다. 같은 원본 버전에서만 복원 여부를 묻고, 원본이 바뀌면 자동 병합하지 않는다. 원본 다시 불러오기는 확인 후 임시 편집을 버린다.
- Unity/Notion/Drive와 자동 동기화하지 않는다. 엔진에 반영할 때는 공통 CSV 변경을 별도 검토한다.

## 소유 파일과 보호 장치

- `src/dev/dialogue-editor/editor-model.js`: CSV 원본 스냅샷·행 ID·순서·Undo/Redo·변경 비교·검증. 새 줄은 기존 엔진 행 형식을 사용한다. 선택지 줄 복제 시 그룹과 선택지 ID도 별도로 생성하므로 원본 선택지가 같이 바뀌지 않는다. 개점 장면의 투영 제외 초기 배치 줄은 삭제/이동을 막는다.
- `editor.js`, `editor.css`: 편집 입력·목록·변경 확인·로컬/웹 구분. 우측 입력 중 전체 화면을 다시 생성하지 않는다.
- `color-picker.js`: 선택 구간 색상 편집·팔레트 입력 검증. 적용 전 색상은 미리보기 메시지에만 전달하며 CSV 모델과 분리한다.
- `preview-bridge.js`: 독립 iframe의 기존 `Game`과 바 화면을 사용한다. 프리뷰 전용 clock이 본편 pump/진행/보상 실행을 막고, 메시지는 같은 출처의 부모 창만 받는다. 입장·퇴장·표정·코스터·빈잔의 상태를 재구성한다. 업데이트 팝업과 본편 입력은 프리뷰에서 열지 않는다.
- `src/shared/dialogue/text-effects.js`: 본편 바와 편집기 공통의 안전한 태그 처리. HTML을 그대로 삽입하지 않는다. CSV 색상/크기/속도 별칭, `shake`, `wave`, `pop`, `color=#RRGGBB`, `size=130%`, `b/i/u`, `br`, 숫자 밀리초 대기 태그를 해석한다. 엔진의 임의 `fx=` 프리셋·TMP sprite 등 미지원 태그는 편집 저장 시 오류를 표시한다. 효과 모션은 웹 CSS 구현이며 Unity 메시 애니메이션의 픽셀 단위 동일성을 보장하지 않는다.
- `src/shared/data/runtime-projection.js`: 기존 빌더와 편집기가 공유하는 원본 → 실행 데이터 투영. `tools/lib/shared-data-views.cjs`는 기존 호출 경로 호환용이다.
- `serve.py`, `tools/dialogue-editor-storage.cjs`: loopback 전용, Host/Origin/임시 토큰/요청 크기 검사, 저장 직렬화, 허용 파일 목록, 원본 revision 충돌 검사, CSV 검증, 백업과 파일 교체. 도중 실패하면 이미 교체한 파일을 복구한다. OS 강제 종료 등 다중 파일 교체 도중 프로세스가 끊긴 경우 백업으로 복구한다.
- `export-package.js`: 동일한 원본과 투영 결과로 CSV/런타임 ZIP 생성. 브라우저에서 다운로드만 수행한다.

검증: `test-dialogue-editor.cjs`는 별도 임시 복사본에서 CSV·런타임 실제 저장/백업/충돌 차단을 검사한다. `test-dialogue-editor-ui.cjs`는 `EDITOR_URL`(기본 `http://127.0.0.1:8124`)의 새 로컬 서버에서 2인 화면·효과·실시간 수정·선택지·Undo·내보내기를 검사한다. 운영 CSV에는 테스트 데이터를 쓰지 않는다.
