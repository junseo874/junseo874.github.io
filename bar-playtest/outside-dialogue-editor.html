연출 배치 확인용 미리보기 · 실제 게임 상태에는 영향을 주지 않습니다.

외부 대사 변경 확인

저장되는 것과 아직 지원하지 않는 것

현재 CSV 구조를 그대로 사용합니다. 회색 항목은 저장 가능한 것처럼 처리하지 않습니다.

  • 거리·집 상호작용의 선택지 장면과 선택지 1~4개를 추가·삭제·순서 변경할 수 있습니다. 문구·추가 조건·불가 사유와 선택 후 연결을 함께 저장합니다. 자동 배경 대화·캠페인 컷씬에는 새 선택지 장면을 삽입하지 않습니다.
  • 선택지는 대사 흐름 안에 들어 있습니다. 직전 말풍선과 실제 거리 선택바를 함께 표시하며, 분기가 나뉠 때만 별도 흐름으로 이동합니다. 신문 NPC의 답변도 질문 바로 뒤에서 수정합니다.
  • 선택 후에는 다음 대사, 대화 종료, 기존 구매·수리 등의 동작, 지정한 대사 분기로 연결할 수 있습니다. ‘대사 분기 만들기’로 후속 대사도 추가합니다. 기존 동작 대신 대사 분기를 지정하면 원래 구매·수리 동작은 실행되지 않습니다.
  • 기존 거래의 가격·재고·완료 상태 검사는 유지합니다. 물품 가격 자체, 신규 아이템·보상 명령 추가는 별도 구현 대상입니다. CSV와 웹 연결 파일을 함께 저장하며 Unity에 자동 적용되지는 않습니다.
  • 캐릭터 이미지·방향·애니메이션·속도는 줄별 미리보기 전용입니다. FieldAnimations에는 동작 리소스 목록이 있지만, 외부 대사 줄의 인물별 클립·유지 범위를 실행하는 연결은 아직 없습니다. 이 부분의 본편 저장은 보류하며 없는 걷기·말하기 시트를 임의로 만들지 않습니다.
  • 현재 외부 실행기는 바의 텍스트 효과 태그를 해석하지 않습니다. 효과 태그·새 타임라인·보상 명령 추가는 보류합니다. 기존 연출 행은 확인만 하며 삭제·복제하지 않습니다.
  • 도입·테라스·회상도 대사를 편집하지만 실제 배경/카메라/합성 연출을 재현하는 타임라인 편집기는 아닙니다. CSV에 없는 TV 다큐 원문·엘리베이터 메뉴·코드 전용 짧은 응답은 별도 기능 연결이 필요합니다.
