편집·동기화 안내

이 화면은 공통 원본 CSV를 보여줍니다. CSV 수정 후 웹 데이터를 다시 생성하고 엔진에 동기화해야 플레이에 반영됩니다. 내려받기는 검색 결과가 아닌 선택한 표 전체입니다.

\N은 값 없음, \E는 빈 문자열입니다. 구조 열의 ID와 연결 관계를 임의로 지우지 마세요.

웹에서 수정: node tools/sync-shared-data.cjs --to-engine
엔진에서 수정: node tools/sync-shared-data.cjs --from-engine
일치 여부 검사: node tools/sync-shared-data.cjs --check
