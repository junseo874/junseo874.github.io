# 쉐이킹 버전 2 · 본편/시뮬레이터 공유 화면

본편 `shake`는 `features/crafting/shake-v2.js`가 이 화면을 `mode=craft`로 열고 `session-craft.js`가 실행 연결을 담당한다. 기존 본편 레시피의 이미 투입한 재료 색/양을 표시하고 입력은 D·A와 E·A를 교대하는 10회로 고정한다. 기존 제조 시도/단계 참조와 창·출처·토큰이 맞는 메시지만 받는다. `craft.elapsed`는 진입 전 누적시간+이 단계 유효시간으로 갱신하여 기존 tick과 중복 계산하지 않는다. 완료 후 V2 점수를 기존 `completion` 0~1에 매핑하고 `failures`, `completed`, `endType` 등 기존 결과 형식으로 `endGimmick()`을 호출한다. 실패도 점수 0으로 기존 큐를 이어가며 별도 연습 결과/재시도/목록 이동은 없다. 안내 완료는 기존 `mix_tutorial_shake`를 사용한다. 큐 변경/취소/초기화 시 프레임과 수신기를 제거한다. CSV 스키마나 엔진은 수정하지 않는다. `test-shaking-main-ui.cjs`로 실제 레시피 큐·시간·정지·완료/실패·정리를 검증한다.

첫 입력은 D다. D는 오른쪽 아래, E는 오른쪽 위로 뻗으며 A는 왼쪽 중앙 수평 자세로 돌아온다. 두 오른쪽 자세의 거리와 각도는 수평축 기준으로 대칭이다. 이동 중에는 키를 숨기고, 도착하면 다음 키 하나가 살짝 확대되며 모서리 빛이 퍼진다. D와 E 표시는 도착 자세에서 큰 틴의 오른쪽 아래·위 꼭짓점에 맞춘다. 올바른 입력만 다음 동작으로 넘어간다. 이동 중 너무 이른 입력과 잘못된 키는 내구도 1칸을 차감한다. 시간 초과는 해당 회차를 MISS로 기록하며 내구도를 유지한다.

쉐이커 윤곽 안에 결합 내구도를 표시한다. 회차 시작에는 윤곽 전체가 빛나고 시간이 지나면 위·아래 선이 오른쪽부터 함께 꺼진다. 남은 선은 경과율 0~25% 흰색, 25~50% 연두색, 50~75% 주황색, 이후 빨간색이다.

결합 내구도는 제목과 내구도 칸을 한 줄로 묶어 쉐이커 윤곽 중앙에 고정 배치한다. 항상 3칸을 표시한다. 남은 칸은 녹색, 시작부터 비어 있던 칸은 회색 윤곽, 잃은 칸은 빨간 윤곽으로 표시한다.

사운드 선택 버튼은 제거하고 음료 선택 UI는 숨긴다. 두 패널이 16:9 화면의 사용 가능한 높이를 채운다. 기본 연습은 코스모폴리탄이며 기존 다른 패턴은 내부 검증용으로 유지한다. 버전 2 음원은 `shaker_02_hit.wav`로 고정하고 URL/설정 초기화/기존 사운드 선호가 이를 바꾸지 않는다. 효과음 음량·음소거는 계속 지원한다.

왼쪽 패널은 결합 전까지 윤곽선과 옅은 노이즈만 표시한다. Space로 결합하면 루나 슬롯 중앙에 SHAKER ASSEMBLED와 START...가 두 줄로 나타난다. 결합 0.6초부터 문구가 사라지며 같은 슬롯의 중앙 가로선에서 위아래로 바 배경과 루나가 열리고, 1초에 방향 입력이 시작되기 전에 화면이 완전히 드러난다. 루나 패널은 `mix_shake_motion` 원본 `Shake.png`의 1280×720 셀 8개를 초당 12프레임으로 재생한다. D는 아래쪽 6번, E는 위쪽 2번 자세로 팔을 뻗고, A는 각각 7→0번과 3→4번을 거쳐 가슴 앞으로 당긴다. 다음 입력은 화면에 보이는 프레임에서 이어지며 마지막 자세는 유지한다. V1과 같은 원본 중심 X=675, 상단 Y=0, 높이 600px로 모든 자세의 구도를 고정하고, 바 배경도 1.2배로 확대한다.

성공 마무리: 마지막 입력 직후 내용물 단면을 숨기고 완료음과 수평 문구·밑줄 표시 → 사선 자세에서 잠시 멈춘 뒤 세로 복귀 → 1.42초에 위쪽 틴이 오른쪽 위로 빠짐 → 위쪽 틴만 페이드아웃 → 아래쪽 틴만 1초 유지 후 결과. 따르기/잔 채우기 연출은 제거했다. 제조 시간은 마지막 입력에서 정지하며 마무리 연출도 설정 일시정지를 따른다. 실패 시 작은 틴이 큰 틴 위를 넘어 오른쪽으로 튕겨 나가면서 왼쪽 모니터의 루나와 배경이 0.32초 동안 중앙선으로 접힌다. 그 자리에 빨간 SHAKE FAILED / SEAL BROKEN 알림이 뜨고 1.5초에 결과로 넘어간다.

루나 강조광은 입력 즉시가 아닌 당기기/뻗기 마지막 프레임에 맞춰 발생하고 현재 프레임의 쉐이커 위치를 따른다. A는 중앙, D와 E는 각각 아래/위 도착 위치를 사용한다. 오른쪽 쉐이커의 충격 링·파편·텍스트는 올바른 입력마다 A는 왼쪽 끝, D와 E는 오른쪽 끝에서 각각 발생한다. 한 회 완료 시 중복 발생하지 않으며 진행도·콤보는 기존처럼 입력 순서를 모두 마쳤을 때만 증가한다.

얼음은 2D 단면 면적의 25%를 차지하는 크기가 다른 10개 조각으로 구성한다(실제 3D 부피 시뮬레이션은 아님). 왼쪽에 불규칙하게 모아 배치한다. A는 수평 복귀와 왼쪽 벽 충돌, D와 E는 오른쪽 벽 충돌로 입력·얼음·액체 방향을 통일한다. 처음 300ms는 입력 방향 충격과 낮은 항력으로 강하게 쏠리고 이후 수류 항력·관성·부력으로 감속하며 벽 충돌·조각 간 겹침을 보정한다. 난수 크기 편차가 있어도 총 면적은 유지한다.

제조 시간은 튜토리얼을 닫고 첫 틴 맞추기 단계에 진입한 순간부터 누적한다. 결합/회전 시간도 포함하고 쉐이킹 진입 시 초기화하지 않는다. 안내·설정 일시정지 시간은 제외하고 성공/최종 실패 판정에서 멈춘 동일 시간을 결과에 표시한다.

위쪽 틴은 원호 좌우 위치에 맞춰 약 ±15~16도까지 함께 기울어진다. 중앙에서는 수직이며, 결합할 때 160ms 정렬 보간에 회전도 포함해 위치·각도가 함께 수렴한다. 튜토리얼 예시에도 동일한 방향의 기울기를 표시한다.

실패로 틴이 분리되는 `pop` 단계에서는 내부 단면 창·얼음은 숨기되 열린 틈에서 외부 액체가 터져 나온다. 최초 64개 물방울을 방출한 뒤 1초 동안 점차 약해지는 배출을 추가하고 중력·속도 방향 꼬리·소멸을 적용한다. 게임 시계 기반으로 일시정지/재시작을 따르며 기존 1.5초 후 실패 결과 시점은 유지한다.

결합 대기 중에는 큰 틴이 아래, 작은 틴이 위에 배치된다. 결합 후 반시계 방향으로 누워 작은 틴이 왼쪽, 큰 틴이 오른쪽을 향한다. 시간 게이지 윤곽도 이 방향을 따르며 글자와 내구도 칸은 똑바로 유지한다. 위쪽 틴은 얕은 원호를 따라 부드럽게 왕복한다(중앙이 높고 양끝이 낮음, 이전 직선 이동 대비 좌우 폭 20% 축소). Space를 누르면 중앙은 3칸, 양옆은 2칸, 양 끝은 1칸으로 결합하며 현재 원호 위치부터 160ms 동안 중앙으로 정렬·하강 결합 후 가로 회전한다. 수평 표시 바와 틴의 좌우 위치는 같은 판정 값을 사용한다.

현재 수정본: 세로·불투명 틴을 Space로 결합 → 1초간 가로 회전 → D·A·E 쉐이킹. 각 방향 입력마다 기존 음원을 재생한다. 1280×720 비율을 유지하고, 중복 인셋과 상단 탐색/설정 버튼은 제거했다. 설정과 목록 복귀는 ESC, 결과 화면에서도 버전을 선택할 수 있다. 원본 재추출은 현재 게임 수정사항을 덮어쓰므로 최신본 업데이트 용도로 실행하지 않는다.

사용자 제공 `lastcall_shaking_v9 (2).html`의 틴 닫기 → 방향 키 순서 입력 → 결과를 독립 iframe에서 실행한다. 다이키리·진피즈·위스키 사워는 이 실험 화면의 연습 프리셋이며 본편 레시피/CSV를 추가하거나 변경하지 않는다.

- 진입: 시뮬레이터 → 쉐이킹 → 버전 선택. 버전 1은 기존 `startMinigame('shake')`, 버전 2만 이 문서를 연다.
- `game.js`는 도구의 물리와 입력을 처리한다. `prop-art.js`와 `guide-art.js`는 실제 게임과 조작 예시에서 결합된 쉐이커 이미지 한 장과 내용물을 함께 기울인다. 분리할 때에는 같은 원본의 두 틴을 사용한다. 결합 이미지와 얼음 방향 시트는 `bar-playtest/tools/build-shaker-poses.py`로 생성한다.
- `session-audio.js`: 원본 합성음을 제거하고 기존 `assets/audio/effects/shaker_01_hit.wav`, `shaker_02_hit.wav`만 사용. 기존 보정 음량과 상위 효과음 버스를 따른다. 얼음 물리 충돌마다 음원을 중복 재생하지 않는다.
- `session-clock.js`: 틴 닫기 대기·MISS 후 재개·실패 결과 지연을 게임 시계로 처리. 일시정지에서 정지, 재시작에서 제거.
- `session.js`, `session.css`: 버전 선택/기믹 목록 복귀, 비활성 창 일시정지, 키보드 포커스 및 화면 맞춤. 상위 문서는 출처와 iframe을 검증한 탐색 메시지만 수신한다.
- 시뮬레이터 진입에는 `mode=craft`가 없으므로 본편 상태에 영향을 주지 않고 연습 결과·재시도/목록 복귀를 유지한다. 본편 연결은 위 어댑터만 담당한다.

원본 재추출은 `node tools/import-shaking-prototype.cjs <원본 HTML>`이며 세션 파일은 덮어쓰지 않는다. 검증: `node bar-playtest/tests/test-shaking-versions-ui.cjs`.
