# 쉐이킹 버전 2 · 시뮬레이터 전용

상단 사운드/음료 선택 UI는 숨기고 두 패널이 16:9 화면의 사용 가능한 높이를 채운다. 기본 연습은 다이키리이며 기존 다른 패턴은 내부 검증용으로 유지한다. 버전 2 음원은 `shaker_02_hit.wav`로 고정하고 URL/설정 초기화/기존 사운드 선호가 이를 바꾸지 않는다. 효과음 음량·음소거는 계속 지원한다.

루나 패널은 도구 좌표/성공 판정과 독립된 입력별 반동작이다. A는 현재 위/아래 뻗은 자세에서 `mid` 중앙 자세로 당겨 멈추고, D는 `high → high2 → push`와 `pull → low2 → low3`를 번갈아 뻗는다. 프레임 간격 65ms, 마지막 자세 유지, 게임 시계 기반 일시정지, 재시작 시 위쪽 D부터 초기화한다. 성공 효과가 자세를 강제로 덮어쓰지 않는다.

성공 마무리: 마지막 입력 직후 내용물 단면을 숨기고 흔들림을 200ms 안정화 → 800ms 동안 처음의 세로·축소 자세로 복귀 → 600ms 동안 위쪽 틴을 들어 분리 → 위쪽 틴만 400ms 페이드아웃 → 아래쪽 틴만 1초 유지 후 결과. 따르기/잔 채우기 연출은 제거했다. 제조 시간은 마지막 입력에서 정지하며 마무리 연출도 설정 일시정지를 따른다. 실패 비산 연출은 별개로 유지한다.

루나 강조광은 입력 즉시가 아닌 당기기/뻗기 마지막 프레임에 맞춰 발생하고 현재 프레임의 쉐이커 위치를 따른다. A는 중앙, D는 위/아래 도착 위치를 사용한다. 오른쪽 성공 효과도 마지막 입력 방향의 벽에 표시한다.

얼음은 2D 단면 면적의 25%를 차지하는 크기가 다른 10개 조각으로 구성한다(실제 3D 부피 시뮬레이션은 아님). 왼쪽에 불규칙하게 모아 배치한다. A는 왼쪽 기울기와 왼쪽 벽 충돌, D는 오른쪽 기울기와 오른쪽 벽 충돌로 입력·얼음·액체 방향을 통일한다. 처음 300ms는 입력 방향 충격과 낮은 항력으로 강하게 쏠리고 이후 수류 항력·관성·부력으로 감속하며 벽 충돌·조각 간 겹침을 보정한다. 난수 크기 편차가 있어도 총 면적은 유지한다.

제조 시간은 튜토리얼을 닫고 첫 틴 맞추기 단계에 진입한 순간부터 누적한다. 결합/회전/확대 시간도 포함하고 쉐이킹 진입 시 초기화하지 않는다. 안내·설정 일시정지 시간은 제외하고 성공/최종 실패 판정에서 멈춘 동일 시간을 결과에 표시한다.

위쪽 틴은 원호 좌우 위치에 맞춰 약 ±15~16도까지 함께 기울어진다. 중앙에서는 수직이며, 결합할 때 160ms 정렬 보간에 회전도 포함해 위치·각도가 함께 수렴한다. 튜토리얼 예시에도 동일한 방향의 기울기를 표시한다.

실패로 틴이 분리되는 `pop` 단계에서는 내부 단면 창·얼음은 숨기되 열린 틈에서 외부 액체가 터져 나온다. 최초 64개 물방울을 방출한 뒤 1초 동안 점차 약해지는 배출을 추가하고 중력·속도 방향 꼬리·소멸을 적용한다. 게임 시계 기반으로 일시정지/재시작을 따르며 기존 1.5초 후 실패 결과 시점은 유지한다.

결합 대기 중에는 큰 틴이 아래, 작은 틴이 위에 배치된다. 위쪽 틴은 얕은 원호를 따라 부드럽게 왕복한다(중앙이 높고 양끝이 낮음, 이전 직선 이동 대비 좌우 폭 20% 축소). 중앙 금색 구간에서 Space를 누르면 현재 원호 위치부터 160ms 동안 중앙으로 정렬·하강 결합 후 가로 회전/확대한다. 수평 표시 바와 틴의 좌우 위치는 같은 판정 값을 사용한다.

현재 수정본: 세로·축소·불투명 틴을 Space로 결합 → 1초간 가로 회전/확대 → A/D 쉐이킹. 각 방향 입력마다 기존 음원을 재생한다. 1280×720 비율을 유지하고, 중복 인셋과 상단 탐색/설정 버튼은 제거했다. 설정과 목록 복귀는 ESC, 결과 화면에서도 버전을 선택할 수 있다. 원본 재추출은 현재 게임 수정사항을 덮어쓰므로 최신본 업데이트 용도로 실행하지 않는다.

사용자 제공 `lastcall_shaking_v9 (2).html`의 틴 닫기 → A/D 순서 입력 → 결과를 독립 iframe에서 실행한다. 다이키리·진피즈·위스키 사워는 이 실험 화면의 연습 프리셋이며 본편 레시피/CSV를 추가하거나 변경하지 않는다.

- 진입: 시뮬레이터 → 쉐이킹 → 버전 선택. 버전 1은 기존 `startMinigame('shake')`, 버전 2만 이 문서를 연다.
- `game.js`, `luna.js`, `settings.js`, `prototype.css`: 제공 HTML에서 분리한 게임. 임베디드 그림/폰트는 `assets/`로 추출.
- `session-audio.js`: 원본 합성음을 제거하고 기존 `assets/audio/effects/shaker_01_hit.wav`, `shaker_02_hit.wav`만 사용. 기존 보정 음량과 상위 효과음 버스를 따른다. 얼음 물리 충돌마다 음원을 중복 재생하지 않는다.
- `session-clock.js`: 틴 닫기 대기·MISS 후 재개·실패 결과 지연을 게임 시계로 처리. 일시정지에서 정지, 재시작에서 제거.
- `session.js`, `session.css`: 버전 선택/기믹 목록 복귀, 비활성 창 일시정지, 키보드 포커스 및 화면 맞춤. 상위 문서는 출처와 iframe을 검증한 탐색 메시지만 수신한다.
- 본편 제조 큐·재료·재화·점수·저장·엔진 CSV에는 연결하지 않는다.

원본 재추출은 `node tools/import-shaking-prototype.cjs <원본 HTML>`이며 세션 파일은 덮어쓰지 않는다. 검증: `node bar-playtest/tests/test-shaking-versions-ui.cjs`.
