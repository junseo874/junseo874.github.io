주 에피소드

조니의 칵테일 복원

  1. 1일차 톰의 부탁 · 3일차 재방문 약속
  2. 1일차 밤 크리스·아일리 → 포트에게 칩 의뢰
  3. 2일차 칩 수령 → 관찰 → 재료 요청
  4. 3일차 직접 제조 → 톰의 반응 → 관계 변화

해결: 찾던 잔을 제공한다. 관계의 변화는 그 뒤 대화와 선택으로 완성된다.

연결된 갈등

삼호의 인정과 책임

  1. 거리 군용 팔 · 빚 · 경호 일
  2. 바 톰에 대한 동경과 밀려난다는 느낌
  3. 다음 날 무장 충돌 가능성 · 소속 사칭
  4. 선택 본인이 철회·정정 → 톰도 책임 인정

남는 것: 빚, 가입 의사, 생계 문제. 해결되지 않은 것을 해결된 보상으로 표시하지 않는다.

선택 탐색 / 복선

거리에서 들리는 이야기

전단·NPC·시바견·라디오·TV는 동네를 이해하는 선택 콘텐츠. 모두 보지 않아도 주 진행을 막지 않는다.

  • 외부 이야기 하위 페이지는 현재 빈 문서.
  • 일부 상호작용 대사는 임시 더미.
  • 포트의 추후 부탁: 복선만 존재, 별도 퀘스트 미구현.
  • 아일리 단기 일자리: 취소선/요약 간 불일치, 현재 필수 이벤트에 넣지 않음.

04 / SOURCE OF TRUTH

무엇이 기준이고,
무엇이 아직 가안인가.

기존 노션 조회본 + 사용자 변경 사항 기준. 2·3일차는 2026.10.04 최신 원문 반영.
설명용 표를 확정 시나리오로 가져오지 않았습니다.

확정 흐름과 사용자 지정 유지 사항
  • 0일차 진토닉·진피즈. 1일차 톰은 드라이 마티니, 아일리는 진피즈.
  • 코스모폴리탄·깔루아밀크, 쿠앵트로·크랜베리 주스·우유·깔루아는 2일차 해금.
  • 톰의 현재 리소스는 정지 이미지. 없는 애니메이션을 있다고 표시하지 않음.
  • 본편은 바·거리·집·밤을 이어 진행. 개발자 바 탭은 바와 연결 체크포인트를 독립 테스트. 외부 탭 2·3일차 출근길은 삼호 근처에서 대사, 퇴근길 집 소파는 자기 기억을 미리 볼 수 있으며 일차는 바뀌지 않음.
제작 전에 결정해야 할 것
  • 2일차 조니 회상의 배합: 와일드 독 45ml / 비터스 5ml / 각설탕 1개 / 얼음·스터. 3일차 제조·복원 판정도 같은 배합으로 적용.
  • 경호 의뢰인·정확한 보수·채무 수치·일자리 조건은 미정. 자동 보상 지급이나 채무 해결을 추가하지 않음.
  • 연구원 신원과 크리스가 떠올린 여자와의 관계는 확정하지 않음.
  • 일기·호감도 성장 UI·경영 확장은 피드백의 아이디어이지 현재 확정 기능이 아님.
