대사 출력음 · 2026-10-11

버전 1(main): 사용자가 첨부한 reference_rhythm_main.wav
버전 2(low, 기본값): 사용자가 첨부한 저음+게인 수치 조정본.mp3

각 첨부 파일에서 단발음 6개씩 추출한 48 kHz / 16-bit / mono WAV.
32 ms 길이, 경계 1.5 ms 페이드, 짧은 구간의 RMS를 맞추고 피크를 -12 dBFS 이하로 제한.
게임 재생 게인은 일반 대화 0.68, 주변 자동 대화 0.34이며 공통 효과음 음량을 추가 적용.
음색별 무작위 피치 변조 없이 6개 변형을 순환. 전역 최소 간격 64 ms.
공백·문장부호만 출력되는 순간, 즉시 전체 보기, 일시정지, Control 스킵에는 신규 출력음 없음.
원본 전체 반복 파일은 배포하지 않고 단발음만 사용한다.
ESC 설정에서 기본음 / 저음·게인 조정 / 끄기를 선택하고 미리 듣기 가능.
