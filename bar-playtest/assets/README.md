# 실행 리소스

| 폴더 | 용도 |
| --- | --- |
| `audio/music/` | BGM |
| `audio/effects/` | 효과음·대사·거리 환경음, 출처/라이선스 포함 |
| `backgrounds/bar/`, `campaign/`, `terrace/` | 장면별 배경 |
| `outside/` | Unity 외부/집 장면의 원본 스프라이트 |
| `characters/` | 인물별 시트, 일반 손님 파츠, 표정 |
| `items/` | 재료·병·잔·도구 |
| `cocktails/` | 칵테일 정적 이미지와 완성 이미지 |
| `serving/atlases/`, `serving/static/` | 제공 애니메이션 아틀라스와 기존 정적 대체 이미지 |
| `tutorials/` | 조작·제조 설명용 캡처 |
| `ui/` | 공통 UI, 선택지, 말풍선, 분리 조각 |
| `fonts/` | 게임 폰트 |
| `reference/` | 검수용 미리보기·내보내기·현재 등록되지 않은 원본 |

## 이름과 교체 규칙

- 등록된 이미지의 `a_<hash>.png` 이름은 `bar-far.png`, `item-gin.png`, `char-...png`처럼 기존 등록 키로 의미를 드러내도록 변경했습니다. 코드의 등록 키 자체는 유지합니다.
- 외부 장면은 원본 영문 이름과 짧은 해시를 함께 사용합니다. 같은 이름의 서로 다른 스프라이트가 충돌하지 않도록 하기 위함입니다.
- 프레임 번호·시트 이름은 원본 애니메이션과의 대응이 중요하므로 임의로 바꾸지 않습니다. 날짜는 최종 실행 폴더명에 붙이지 않습니다.
- 원본 크기·알파·프레임 레이아웃을 보존합니다. 배치 정리를 위해 리사이즈/재압축하지 않습니다.
- 실제 URL은 `data/runtime/` 등록 정보 또는 해당 기능 모듈에서 관리합니다. 등록되지 않은 원본은 삭제하지 않고 `reference/unmapped/`에 보존합니다.
- 새 이미지는 용도 폴더에 추가하고 등록부·관련 검수 항목을 함께 갱신합니다. `assets/` 루트에 파일을 다시 쌓지 않습니다.
- 음원 출처/라이선스 파일은 대응하는 음원과 함께 둡니다.

리소스 정리 이전 경로와 새 경로: `../../docs/architecture/path-migrations.json`.
