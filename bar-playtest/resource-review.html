미제작 리소스 목록

더미·공용 더미·미등록 리소스를 분류별로 모았습니다. 현재 쓰는 대체 이미지와 빠진 용도를 함께 확인하세요.

등록된 정식 이미지의 공용 사용과 일반 코드 UI·연출, 거리 행인 NPC는 제외합니다. 캐릭터 미제작 목록은 현재 톰 거너·시바·집 테라스 크리스만 표시합니다. 단, 작업자가 미제작으로 확인한 UI 화면은 포함합니다. 제공 애니메이션 없이 정적 이미지로 대체하는 항목은 별도로 표시합니다.

시뮬레이터의 현재 등록 데이터 기준입니다. 아직 등록하지 않은 별도 파일의 제작 완료 여부까지 판정하지는 않습니다.

LIVE SIMULATOR / 독립 테스트

화면 테스트

화면의 뒤로가기 또는 브라우저 뒤로가기로 보던 리소스 목록에 돌아옵니다. 화면을 클릭한 뒤 조작하세요. 마우스 호버·클릭·키보드는 실제 게임과 동일합니다. 이 테스트의 진행 상태는 본편에 연결되지 않습니다. 소리·언어 설정은 기존 브라우저 설정을 사용합니다.
