# 외부 거리 최적화 검수 — 2026-11-13

- 캐릭터별 WebGL 화면 크기 재설정을 없애고 작은 화면을 재사용한다.
- 원본 크기의 출력 셀을 재사용해 캐릭터와 물웅덩이 반사의 픽셀을 유지한다.
- 화면 밖 증기만 계산을 생략한다. 다시 보일 때에는 현재 시점으로 그린다.
- OS 모션 설정 조회 객체를 재사용한다. 설정 변경은 실시간 반영된다.
- 원본 해상도, DPR, 효과 강도/개수, 애니메이션 속도, 게임 시계는 유지했다.

## 비교 조건

로컬 Chrome, 1280×720 CSS / DPR 2 (실제 2560×1440), 같은 장면의 110프레임 중 준비 후 90프레임 측정. CPU 제한 없음 및 CDP 4배 CPU 제한. 게임 진행을 고정한 렌더링 벤치마크이며, 실제 저사양 기기의 전체 플레이 FPS나 GPU 사용률 측정은 아니다. `cpu`는 화면 그리기 호출 시간, `frame`은 requestAnimationFrame 간격이다. 평균 FPS 환산은 1000 / frame.mean이다.

`before.json`, `after.json`에 장면별 원자료가 있다. `benchmark.cjs`는 HTTP 서버 8123번 포트에서 독립 실행한다. 이전 소스 세 파일이 들어 있는 디렉터리를 `STREET_BASELINE_DIR`로 지정하면 이전 버전을 브라우저에 제공해 비교할 수 있다. 브라우저 검사를 함께 돌리면 성능 수치가 오염되므로 단독 실행해야 한다.

## 시각 검증

`visual-comparison.json`: 같은 장면/시간에서 원래 캐릭터 조명 렌더러와 변경 렌더러를 번갈아 적용한 최종 캔버스 비교. 상점 우천·모닥불·복도·상점 건조 네 장면 모두 변경 픽셀 0. 증기의 화면 밖 생략은 별도 전용 검사에서 화면에 보이는 모든 픽셀 일치 확인.

`shops.png`, `camp.png`, `corridor.png`, `dry.png`는 변경 후 실제 장면. 네 장면 모두 WebGL 오류 없음.
