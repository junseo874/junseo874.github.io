# 외부 검사 실패 8개 원인 분석과 수정

2026-11-13. 이전 성능 작업에서 남은 8개를 변경 전 다시 실행해 모두 재현했다. `before.json`과 `before-*.log`가 그 기록이다. 엔진과 원본 이미지는 읽기 전용으로 확인했다.

최종 결과: **외부 83/83, 기본 43/43 통과, 실패 0개**. 기존 실패 8개도 같은 전체 묶음 안에서 모두 통과했다. 구조·경로·모듈·탐색 검사 4개와 별도 960×600 / DPR 2 창문 효과 검사도 통과했다.

## 원인과 처리

ProjectSettings의 원인 변경은 엔진 커밋 `8d616a1c`에서 확인했다. 부모 버전의 SHA-256은 기록된 `14536e8f…`와 일치하며, 해당 변경은 입력 처리 방식 한 줄이다. 효과에 필요한 값을 무시하거나 최신 전체 해시로 무조건 바꾼 것이 아니다.

## 실제 화면 확인

변경 전 화면은 `before-*.png`, 확인 후 화면은 `after-*.png`다. 새 접점 검수 사진만 윗벽을 중심으로 잡았다. 본편 카메라의 일반 구도를 바꾸지 않았다. 나머지는 실제 플레이 장면 캡처다.

전체 검사 결과와 개별 실패 여부는 같은 폴더의 `outside.log`, `smoke.log` 및 `validation.json`에 기록했다. 새와 모닥불처럼 표현이 이미 맞았던 부분은 그대로 유지하고, 검사가 원본 접점·현재 배치·실제 화면을 함께 확인하도록 수정했다. 카메라 고정, 몸체 벽 침범 금지, 비의 실내 누출 금지와 같은 원래 동작 기준은 낮추지 않았다.

집 창문은 1280×720 / DPR 1과 960×600 / DPR 2에서 각각 실제 렌더 24시점을 비교했다. 두 경우 모두 실내·틀·바닥 변경 픽셀 0, 유리 밖 물방울 0이다. 외부 검사는 반사·안개·조명·스캔라인, 빗방울 180초 누적, 실제 키 입력과 화면 크기 변경도 포함한다. 캡처 검수는 로컬 Chrome에서 수행했으며, 다른 브라우저나 실제 저사양 기기까지 검증했다는 의미는 아니다.
