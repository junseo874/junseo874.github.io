# 시바견 말풍선 위치 수정 · 2026-11-13

시바견의 네 애니메이션 셀은 폭이 달라, 현재 셀의 폭/피벗 좌표계로 전체 애니메이션 알파 경계를 재계산하면 머리 기준점이 흔들렸다. 말풍선 머리 계산을 등록된 애니메이션의 첫 셀 좌표계로 통일했다. 배우 위치·방향·카메라 추적과 실제 애니메이션 그림은 유지했다.

동일한 실제 웹 장면에 수정 전 소스를 주입하면 위치 고정 검사가 실패한다(`before.log`). 수정 후에는 180프레임 동안 실제 월드 앵커와 DOM 말풍선 위치가 고정된다(`after.log`). 루나 대기/걷기/달리기, 시바견, 삼호의 등록 애니메이션도 프레임별 기준점이 같다. `verified.png`는 실제 대사가 표시된 브라우저 캡처다.

검증: 외부 83/83, 기본 43/43 통과. 별도 새 말풍선 검사도 통과(외부 묶음에 이후 등록). UI 48개 중 최초 46개 통과. 나머지 두 항목은 본편에서 이미 제외된 롱아일랜드를 포함한 과거 14개 레시피 기대값과 모바일 리소스 상세창의 높이 초과였다. 제외 조건/현재 13개 검사 및 상세창 높이 제한을 수정한 후 해당 두 검사를 재실행해 모두 통과했다. 최초 결과와 재검사 결과는 각각 보존했다. 모바일 창은 8개 뷰포트와 실제 캡처로 확인했다.
