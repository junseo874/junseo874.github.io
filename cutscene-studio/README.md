# 컷씬 편집기

`index.html`이 편집기 진입점입니다. 본편도 이 편집기의 런타임 모듈을 공유합니다.

- `src/`: 편집 모델·키프레임·렌더링·편집 UI
- `styles/`: 편집기와 공유 대사 스타일
- `data/`: 가져온 도입부 대사
- `assets/`: 편집기 기본 리소스
- `tests/`: 모델/브라우저 smoke tests

공유 모듈을 바꿀 때는 본편 `bar-playtest/tests/test_cutscene_library_ui.cjs`도 확인합니다. 브라우저의 기존 프로젝트/에셋 저장소 키는 변경하지 않습니다.

## 트레일러 미리보기

`trailer.html`은 본편에 연결되지 않는 약 2분 4초의 홍보용 미리보기입니다. 시뮬레이터 컷씬 목록과 편집기 상단에서 열 수 있습니다. 엔진 타임라인 제작 대상 5개에는 포함하지 않습니다.

- `src/trailer-scenes.js`: 사용자 지정 순서·문구·구간 길이. 게임 진행 데이터나 CSV가 아닌 이 화면만의 편집 목록입니다.
- `src/trailer-preview.js`: 독립 재생 시계, 탐색, 암전·글리치·음향, 동일 손 동작 프레임으로 연결하는 8종 제공 화면.
- `src/trailer-game.js`: 별도 iframe 안의 웹 표시 기능을 재사용합니다. 본편 진행 tick과 저장을 막고 캐릭터·테라스·외부 대화·병 개봉을 표시합니다. 실제 게임 탭이나 CSV를 바꾸지 않습니다.
- `assets/trailer/`: 사용자가 제공한 촬영본에서 추출한 무음 720p 클립. 같은 파일명을 유지하면 새 촬영본으로 교체할 수 있습니다. `team`은 팀 로고, `street`는 거리 걷기, `pour-*`는 재료 따르기, `shake`/`stir`는 제조, `boobi`는 부비 등장입니다. 원본 영상은 변경하지 않았습니다.
- 도입~거리와 테라스·외부 장면에 빗소리를 넣습니다. 모든 테라스는 비가 옵니다. 도입 암전~서울 문구에는 본편 `LunaRainGlass`를 재사용하며 1.8초에 걸쳐 나타납니다. 팀 로고 뒤에는 1.1초 여백을 둡니다.
- `trailer-effects.js`는 감정별 2단 중앙 텍스트 연출, 엔진 `SH_TitleGlitchPanel.shader`의 24개 띠/2.86초 주기/47·19 깜빡임을 반영한 로고, 원본 효과음 타이밍을 소유합니다. 효과음은 미리 디코딩해 재생·탐색·일시정지에 맞추며 팝업 소리와 음악은 없습니다.
- 송하루의 임시 대사는 “오늘은 어떤 한 잔을 추천해 주실 건가요?”이며 본편 CSV에는 쓰지 않습니다. 감정 뒤 테이블에는 아일리 스크류드라이버, 톰 드라이 마티니, 삼호 갓파더, 포트 진피즈를 배치합니다.
- 거리 촬영본은 0일차 퇴근길의 왼쪽 걷기입니다. 따르기는 진(집어 들기부터) → 탄산수(약 20%부터) → 맥주(거품 포함 40% 이상부터), 병따기는 원 타이밍부터, 이후 신형 쉐이킹 → 스터 6초 → 제공 1.5초입니다. 제공은 원본 20fps로 손 프레임을 공유하며 8종을 전환합니다.
- 손님 몽타주는 크리스 제외, 1인당 1.85초입니다. 도입 크리스까지 모든 바 대사는 초당 36자로 통일합니다. 정체 글리치는 텍스트에만 적용합니다. 외부는 선택 직전 대화 2줄 → 선택지 순으로 보여주며, 원래 선택지가 없는 기신교는 대화를 이어갑니다. 부비는 촬영본의 2.7초(상자에서 나온 직후)에서 끊습니다.
- `montage`가 같은 인접 컷(손님/표정, 제조~제공, 외부 상호작용~부비)은 페이드 없이 전환합니다. 동영상 첫 프레임도 미리 준비합니다. 외부 팝업 효과음은 트레일러 iframe에서만 차단합니다.
- 확인: `node cutscene-studio/tests/test-trailer-ui.cjs` (로컬 서버 8123 필요).
