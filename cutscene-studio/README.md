# 컷씬 편집기

`index.html`이 편집기 진입점입니다. 본편도 이 편집기의 런타임 모듈을 공유합니다.

- `src/`: 편집 모델·키프레임·렌더링·편집 UI
- `styles/`: 편집기와 공유 대사 스타일
- `data/`: 가져온 도입부 대사
- `assets/`: 편집기 기본 리소스
- `tests/`: 모델/브라우저 smoke tests

공유 모듈을 바꿀 때는 본편 `bar-playtest/tests/test_cutscene_library_ui.cjs`도 확인합니다. 브라우저의 기존 프로젝트/에셋 저장소 키는 변경하지 않습니다.

## 트레일러 미리보기

`trailer.html`은 본편에 연결되지 않는 약 1분 55초의 홍보용 미리보기입니다. 시뮬레이터 컷씬 목록과 편집기 상단에서 열 수 있습니다. 엔진 타임라인 제작 대상 5개에는 포함하지 않습니다.

- `src/trailer-scenes.js`: 사용자 지정 순서·문구·구간 길이. 게임 진행 데이터나 CSV가 아닌 이 화면만의 편집 목록입니다.
- 첫 암전은 4.5초이며, 빗소리는 처음 4초 동안 무음에서 완만한 곡선으로 커집니다. 빗방울과 다음 테라스의 연결은 유지합니다.
- 마지막 테라스의 크리스 → 루나는 동일 대화 화면을 유지하며 페이드 없이 말풍선만 교체합니다. 크리스는 진입 페이드 0.65초 뒤 타이핑을 시작하고, 출력 완료 후 약 1.3초 읽을 시간을 둡니다. 배경 DOM·빗방울·캐릭터 애니메이션 시계는 화자가 바뀌어도 초기화하지 않습니다.
- `src/trailer-preview.js`: 독립 재생 시계, 탐색, 암전·글리치·음향, 동일 손 동작 프레임으로 연결하는 8종 제공 화면.
- `src/trailer-game.js`: 별도 iframe 안의 웹 표시 기능을 재사용합니다. 본편 진행 tick과 저장을 막고 캐릭터·테라스·외부 대화·병 개봉을 표시합니다. 실제 게임 탭이나 CSV를 바꾸지 않습니다.
- `assets/trailer/`: 사용자가 제공한 촬영본에서 추출한 무음 720p 클립. 같은 파일명을 유지하면 새 촬영본으로 교체할 수 있습니다. `team`은 팀 로고, `street`는 거리 걷기, `pour-*`는 재료 따르기, `shake`/`stir`는 제조, `boobi`는 부비 등장입니다. 원본 영상은 변경하지 않았습니다.
- 도입은 우측의 희미한 청록·남보라 도시 색감입니다. 암전 → 테라스 → 팀 로고는 하나의 `LunaRainGlass` 시뮬레이션과 시계를 공유하여 빗방울이 사라졌다 다시 생기지 않습니다. 테라스 자체의 중복 유리 효과만 미리보기에서 차단합니다. 팀 로고는 기존 배경 색감을 유지하고 영상은 1.3배속, 마지막 0.9초에 비와 함께 암전합니다. 1.3초의 완전 암전 후 서울 문구는 비 없는 검은 화면에 표시합니다. 거리와 후반 테라스·외부 장면은 다시 각 장면의 비를 사용합니다.
- `trailer-effects.js`는 감정별 2단 중앙 텍스트 연출(8단어를 4초에 전환), 제공된 Honeycam GIF를 참고한 로고의 짧고 굵은 띠 어긋남/즉시 복구, 원본 효과음 타이밍을 소유합니다. 마지막 “저는…” 뒤에는 1.4초 암전, 흰색 원본 로고의 1.5초 페이드 인, 이후 짧은 글리치 순서입니다. 청색 광채가 합쳐진 로고나 연속 잔떨림은 사용하지 않습니다.
- 대사 소리는 본편의 `low-1`~`low-6` 원본을 글자 공개에 맞춰 한 번씩 재생하며, 재생 속도는 1배속·최소 간격은 본편과 동일한 64ms입니다. 공백·구두점·탐색으로 건너뛴 글자는 소리를 예약하지 않습니다. 짧은 샘플의 루프 재생은 금지합니다. 제조 효과음도 원본 재생 속도를 유지하고, 팝업 소리와 음악은 없습니다.
- 송하루의 임시 대사는 “오늘은 어떤 한 잔을 추천해 주실 건가요?”이며 본편 CSV에는 쓰지 않습니다. 감정 뒤 테이블에는 아일리 스크류드라이버, 톰 드라이 마티니, 삼호 갓파더, 포트 진피즈를 배치합니다.
- 거리 촬영본은 0일차 퇴근길의 왼쪽 걷기입니다. 따르기는 진(집어 들기부터) → 탄산수(약 20%부터) → 맥주(거품 포함 40% 이상부터), 병따기는 원 타이밍부터, 이후 신형 쉐이킹 3.15초 → 스터 2.85초(각 약 5칸까지) → 제공 3.3초입니다. 제공은 원본 20fps로 1.5초 동안 손 프레임을 공유하며 8종을 전환한 뒤, 드라이 마티니의 마지막 프레임을 약 1.8초 유지합니다. 유지 중 제공 효과음은 반복하지 않습니다.
- 손님 몽타주는 크리스 제외, 1인당 1.85초입니다. 도입 크리스까지 모든 바 대사는 초당 30자로 통일합니다. 정체 글리치는 텍스트에만 적용합니다. 외부는 선택 직전 실제 대사 1줄 → 본편 타이핑 완료 후 0.6초 → 선택지 순서로 4.6초씩 보여줍니다. 외부 55자/초·테라스 60자/초 및 마침표 쉼 규칙은 본편을 재사용하고 배속하지 않습니다. 원래 선택지가 없는 기신교는 대화를 이어갑니다. 부비는 촬영본의 2.7초(상자에서 나온 직후)에서 끊습니다.
- `montage`가 같은 인접 컷(손님/표정, 제조~제공, 외부 상호작용~부비)은 페이드 없이 전환합니다. 동영상 첫 프레임도 미리 준비합니다. 외부 팝업 효과음은 트레일러 iframe에서만 차단합니다.
